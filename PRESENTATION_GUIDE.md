## Current technical status

- Power flow converges in 6 Newton--Raphson iterations.
- Report figures/tables are generated by `generate_kundur_ex126_report.m`.
- Table 4 / Kundur Table E12.3 real-imag eigenvalue plot is available at:
  - `docs/source/figures/kundur_ex126/full_eigenvalue_map.png`
- Fault simulation plot includes:
  - bus voltage magnitudes for Bus 1--11
  - active power for G1--G4
  - rotor-angle differences
  - rotor speed deviations
- 6th-order SSSA uses the Sauer--Pai model:
  - states per generator: `[delta, omega, E'_q, E'_d, psi''_d, psi''_q]`
  - 4 machines -> 24 states before reference reduction
- 6th-order DAE operating-point residual is near machine precision.
- Remaining discussion item for the teacher: interarea damping real part is sensitive to angle-reference/load/damping assumptions.
