# GFL/GFM state-transfer proof

Two language editions share the same equations, proof and generated numerical values.

- `mode_switch_proof_th.tex`: Thai entry point.
- `mode_switch_proof_en.tex`: English entry point.
- `mode_switch_proof_body.tex`: shared bilingual report source (required by both).
- `verification_values.tex`: numerical values generated by the MATLAB check.
- `verify_mode_switch_proof.m`: reproducible reset/RHS verification using production callbacks.
- `verification.txt`: full-precision numerical output.

Compile each entry point twice using XeLaTeX, from this directory:

```text
xelatex -interaction=nonstopmode -halt-on-error mode_switch_proof_th.tex
xelatex -interaction=nonstopmode -halt-on-error mode_switch_proof_th.tex
xelatex -interaction=nonstopmode -halt-on-error mode_switch_proof_en.tex
xelatex -interaction=nonstopmode -halt-on-error mode_switch_proof_en.tex
```

Requirements: XeLaTeX, standard LaTeX packages listed in the source, Latin Modern,
and TH Sarabun New. The Thai source first tries the installed font family and then
the inspected Windows font directory. Adjust that fallback path if necessary.

To rerun the MATLAB check, keep this directory under
`Power-flow/docs/output/pdf/mode_switch_proof`, add this directory to the MATLAB
path, and call `verify_mode_switch_proof`. The script locates the repository,
initializes its paths, and overwrites only the two generated verification outputs
in this report directory. It does not change production code or existing results.

The 600 checks are local mode-transfer and instantaneous-RHS tests, not 600
full-network transient simulations. The report distinguishes physical port
continuity from controller-coordinate continuity, derivative continuity and
post-switch stability. It does not modify the original slides or graphs.
