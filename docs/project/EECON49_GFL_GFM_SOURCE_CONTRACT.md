## State and input order

The production device has 16 fixed states:

1. common: `[i_d,i_q,V_dc]`;
2. GFL-only: `[delta_PLL,xi_PLL,xi_P,xi_Q,xi_Id,xi_Iq]`;
3. GFM-only: `[delta_VSG,omega_VSG,E,xi_Vd,xi_Vq,xi_Id,xi_Iq]`.

The GFL active set is `1:9` (9 states). The GFM active set is
`[1:3,10:16]` (10 states). The inactive branch is held at its transfer anchor;
no state is silently removed.

The source publishes command/actuation-delay blocks (Eqs. (20)--(21), Fig. 2)
whose per-branch states `Vd_del,Vq_del` were previously carried, giving 20
fixed states with GFL active set `1:11` and GFM active set `[1:3,12:20]`. The
delay time constant is NOT source-defined; the owner-set value is
`PROJECT_DERIVED` from digital-VSC control physics, `T_d = 1.5/f_sw` (one
computation sample plus 0.5 sample PWM/zero-order hold). At the utility-scale
switching frequency `f_sw = 5 kHz` this is `T_d = 0.3 ms`, more than 300x
below the phasor step `dt = 0.10 s`. By singular perturbation (`T_d << dt`)
the fast first-order lag collapses onto its slow manifold `v_del = v_cmd`, so
the four delay states are removed and the AC-filter equations consume the
commanded voltage directly (defect `TD-2026-08-12-01`; the earlier placeholder
`T_d = 0.02 s` had produced a spurious +1.29 @ 11.4 Hz all-GFL mode). The
retained equilibrium and dynamics are unchanged; the reduction is a state-order
change, not an equation change. Inputs are `[P_ref,Q_ref,E_ref]`. Both branches
consume the first two inputs. GFM consumes the third as the external amplitude
reference in its voltage-state equation; it is not a measured terminal voltage.
GFL retains the same three-input superset ABI but does not consume `E_ref`.

## Bases, frames, and signs

Let `kappa=Sbase/Mbase`. Controller current and power are on device base;
network current and input references are on system base:

```text
I_sys = (i_d + j i_q) exp(j theta) / kappa
S_sys = V conj(I_sys)
P_inv = kappa Re(S_sys),  Q_inv = kappa Im(S_sys)
```

Positive `P,Q` mean injection into the network. With the controller d axis
aligned to terminal voltage, positive injected Q corresponds to negative
`i_q`. `L_f` is the per-unit filter reactance; therefore the current derivative
uses `omega_b/L_f`. The project network uses a synchronous rotating reference,
so the absolute source angle equations are represented as relative angles:
`dot(delta)=omega_b(omega_pu-1)`.

## Common plant and project-derived DC port

The AC-filter equations are the standard power-invariant dq equations. After
the command-delay reduction (`v_del = v_cmd`) the plant consumes the commanded
converter voltage directly:

```text
dot(i_d) = (omega_b/L_f)(Vcd_cmd - Vgd - R_f i_d + omega_pu L_f i_q)
dot(i_q) = (omega_b/L_f)(Vcq_cmd - Vgq - R_f i_q - omega_pu L_f i_d)
```

The circular `Imax=1.2 pu` limiter acts on the current reference generated by
the outer P/Q or voltage loop before the inner current PI.  The physical
filter currents remain the differential states in the two AC-filter equations;
they are not algebraically clipped and their derivatives are not projected.
Consequently a fault transient may briefly exceed the reference limit and is
reported honestly.  Clipping the states would change the terminal KCL port;
projecting their derivatives creates a nonsmooth complementarity problem that
is absent from the governing filter equations.

The DC energy equation is

```text
C_dc dot(V_dc) = I_dc - P_ac/V_dc
P_ac = Vcd_cmd i_d + Vcq_cmd i_q.
```

The missing source-current law is closed without a new integral state:

```text
I_dc = P_ac/V_dc + (C_dc/T_dc)(V_dc,ref-V_dc)
```

The exact instantaneous-power feed-forward supplies the converter-side power
being drawn from the DC link. Substitution gives
`dot(V_dc)=(V_dc,ref-V_dc)/T_dc`; hence the unpublished closure does not move
the sourced AC equilibrium. The proportional term uses `T_dc=0.10 s`, a
frozen `PROJECT_DERIVED` design value, not a fitted result. Nonpositive or
nonfinite `V_dc`, nonpositive `T_dc`, and invalid terminal voltage fail closed.

## GFL and GFM ownership

GFL uses the PLL angle and PI integrator, outer P/Q PI loops, and inner
current PI loops. Its frequency is measured by the PLL. GFM uses the
VSG swing equation, Q--V amplitude state, outer voltage PI loops, the common
inner current PI structure, and its own VSG angle. Command/actuation-delay
blocks are represented by their slow manifold `v_del = v_cmd` (above); no GFM
derivative,
output, state name, or metadata row refers to a PLL.

The GFM amplitude equation in project injection signs is

```text
dot(E) = [k_Q (kappa Q_ref-Q_inv) - k_E (E-E_ref)]/tau_E.
```

`E_ref` is immutable case/event input data during the reduced equilibrium
solve. Terminal reactive power is solved; neither `Q_ref` nor `E_ref` is
overwritten to manufacture an equilibrium.

The paper-to-project Q and cross-coupling signs are transformed only to satisfy
the network injection convention above; independent tests enforce terminal
`S=V*conj(I)`, equilibrium residual, and rigid-frame covariance.

## Initialization, transfer, and residuals

Device initialization uses the in-house PF terminal voltage and the exact
case-defined `P_ref,Q_ref`. Current, converter command voltage, PI anchors,
`V_dc`, VSG speed, and voltage magnitude are initialized so every active
differential residual is zero within numerical precision.

At a GFL/GFM event, the project-derived transfer:

- preserves common `i_d,i_q,V_dc` and terminal `V,I,P,Q`;
- initializes only the target controller at the same terminal port;
- carries PLL frequency into VSG speed for GFL-to-GFM;
- carries VSG speed into the GFL PLL integrator for GFM-to-GFL;
- rejects the transaction if `|I_right-I_left|>1e-10` before the network
  right-limit KCL transaction is accepted.

Equilibrium and TS remain governed by the in-house composite residuals,
Jacobian/Newton contracts, declared tolerances, and fail-closed event logic.
The DC controller introduces no external solver and no acceptance relaxation.
