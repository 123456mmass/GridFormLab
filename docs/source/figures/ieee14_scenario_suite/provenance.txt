The _fv SHEET CARRIES THE SIGNALS THE SWITCHING INDEX IS BUILT FROM.
  The supervisor consumes S = min(1,max(0,0.5*J_V+0.5*J_f)) with
    J_V = |V_i - V_healthy(bus i)| / dV_base   (dV_base = 0.10 pu)
    J_f = |f_COI - f0|                / df_base   (df_base = 0.50 Hz)
  so f is ONE system centre-of-inertia trace, not a per-converter frequency (J_f is
  identical across converters by construction), and V is each converter bus's own
  magnitude measured against THAT BUS's healthy power-flow level, not against 1.0 pu.
  The dashed rules on both panels are the J = 1 band edges. Every sheet set RE-DERIVES
  J_V, J_f and S from exactly what it plots and refuses to draw if they do not match
  the run's published values; the residuals are listed per scenario below.

The GFL/GFM trace is MASKED to NaN wherever a converter is out of service.
  device_modes_history holds "tripped" for such a device and the 0-1 trace tests only
  for "gfm", so an unmasked panel would draw a departed converter on the GFL level --
  i.e. as one that is following the grid. P, Q and |V| are NOT masked: a tripped
  converter injects no current, so its zero is measured, and its bus stays energised
  by the rest of the island, so |V| there remains a network measurement.

The mode traces carry NO display offset. Where several converters share a mode the
  traces coincide, and that coincidence IS the fact -- a synchronous mode change; a
  nudge would invent a difference that is not there. Line style separates them.

The x axis spans the REQUESTED horizon on every sheet. A run that stopped early is
  marked with a red validity rule at its last accepted sample instead of having the
  axis cropped to its data.

Y WINDOWS on a FAULTED arm are computed over the OPERATING BAND -- the run minus its
  fault window plus 50 ms -- and anything that leaves the window is annotated AT THE
  FRAME with its peak value. Measured reason, on sg_fault_bus9: |V| spans
  [0.258 1.864] pu over the whole run but [0.551 1.138] pu outside the fault window --
  2.74x the span for 5 % of the samples -- and P spans 2.72x. The 1.86 pu peak is the
  12-sample right-limit burst of the atomic fault-clear transaction, back inside 1.15 pu
  within 1.1 ms. Letting it set the axis compresses the islanded operating band, and the
  J_V = 1 envelope the _fv sheet exists to show, into a few percent of the panel.
  NOTHING is dropped, filtered or clipped from the data: every sample is plotted, and
  every value outside a window is listed per scenario below. An arm with no scheduled
  fault excludes nothing -- measured span ratio exactly 1.00x -- so its window is the
  whole run and its off-scale list is empty.
