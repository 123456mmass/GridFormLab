  column is a "GFM Mode Active" STRIP above a data panel:
    (a) P_i, the active power each converter delivered
    (b) Q_i, the reactive power each converter delivered, against zero
  The strip is a separate axes, not an overlay inside the data area, so a bar can never
  sit on a trace and the traces keep the whole panel height.

Pure cache reader. Nothing is simulated, re-solved, smoothed, filtered, decimated,
  clipped, offset, interpolated or padded: every plotted sample is a raw accepted
  value from the stored trajectory.

NEITHER PANEL IS MASKED FOR SERVICE. The mode strip is masked -- a converter out of
  service has no mode -- but P and Q are not: a departed converter injects no current,
  so its zero is a MEASURED injection and hiding it would hide the outage. The masked
  sample count is listed per scenario below.

THE MODE STRIP is the outcome of the supervisor comparing S against Gamma_on/Gamma_off,
  which is why this page refuses to draw without the threshold pair the run used. Each
  bar spans one CONTIGUOUS grid-forming interval at its TRUE extent -- no minimum width
  is applied, because widening a short interval to make it visible would draw a
  grid-forming stretch that did not happen. A converter with no bar was never
  grid-forming on this arm, and that absence is the fact.

Y WINDOWS on a faulted arm are computed over the OPERATING BAND -- the run minus its
  fault window plus 50 ms -- and anything outside is annotated AT THE FRAME with its
  peak value. NOTHING is dropped, filtered or clipped: every sample is plotted and every
  value outside a window is listed below.

The x axis spans the REQUESTED horizon, not the last accepted sample: cropping to
  the data would draw a truncated run as a finished one.
