\title{\textbf{IEEE 14-Bus GFL$\leftrightarrow$GFM Switching}\\
\large Corrected full-state equations, automatic formation, and the 250-s chronology}
\author{}
\date{10 August 2026}

\begin{document}
\maketitle

\begin{abstract}
This report describes the corrected project-owned model used for one six-state EMF6 synchronous
generator (SG) and four switchable inverter-based resources (IBRs). The correction restores the
physical controller ownership: grid-following (GFL) mode contains a phase-locked loop (PLL), while
grid-forming (GFM) mode forms its angle through a virtual swing equation and contains no PLL.
Both modes share the AC-filter current and dc-link states. The requested chronology uses
$\Delta t=0.1$~s and events at 20, 50, 85, 85.15, 110, and 145~s, with a diagnostic endpoint of
250~s. The latest generated accepted trajectory ends at \RunEnd~s. Its observed network-voltage
range is \RunVMin--\RunVMax~pu and its aggregate-frequency range is
\RunFMin--\RunFMax~Hz. These extrema are reported as results, not used as tuned acceptance bands.
The maximum accepted residual is \RunResidual, the deepest step subdivision is
\RunSubdivision, and the number of rejected domain trials is \RunDomainRejects. The SG reclosed
at \RunReclose~s. Staged release retained \RunFinalGFMCount{} authenticated GFM resource(s), at
bus(es) \RunFinalGFMBuses, because an SG-online all-GFL equilibrium is small-signal unstable.
Numerical completion and operational readiness are reported separately; raw excursions are never
hidden or used to tune a gate.
\end{abstract}

\section{Scope, evidence classes, and non-goals}

The system base is $S_{base}=100$~MVA and $f_0=60$~Hz. SG1 is connected at bus~1;
IBR1--IBR4 are connected at buses 2, 3, 6, and 8. Network equations, power flow, equilibrium,
small-signal analysis, and time-domain simulation use project-owned Base MATLAB code. The model
choices are separated as follows.

\section{Corrected fixed state and input contracts}

Every IBR stores one 20-state vector of constant dimension. For presentation, a fixed permutation
groups the GFM/plant block before the GFL-control block:
\begin{align}
x_{IBR}&=\begin{bmatrix}x_{GFM}\\ x_{GFL}\end{bmatrix}
=\Pi\,x_{runtime},
\label{eq:xibr}\\[4pt]
x_{GFM}&=\begin{bmatrix}i_d,\,i_q,\,V_{dc},\,\theta,\,\omega,\,E,\,
\xi_{Vd},\,\xi_{Vq},\,\xi_{Id}^{gfm},\,\xi_{Iq}^{gfm},\,
V_{d,del}^{gfm},\,V_{q,del}^{gfm}\end{bmatrix}^{\!T},
\label{eq:xgfm}\\[4pt]
x_{GFL}&=\begin{bmatrix}\delta_{PLL},\,\xi_{PLL},\,\xi_P,\,\xi_Q,\,
\xi_{Id}^{gfl},\,\xi_{Iq}^{gfl},\,V_{d,del}^{gfl},\,V_{q,del}^{gfl}\end{bmatrix}^{\!T}.
\label{eq:xgfl}
\end{align}
Here $\Pi$ is a reporting-only permutation: production keeps its existing ABI and no state is
reordered in code. The first three entries of $x_{GFM}$ are the common physical plant and remain
active in either mode. GFL activates those three plus the eight-state $x_{GFL}$ controller and
freezes the nine GFM-only states. GFM activates all 12 entries of $x_{GFM}$ and freezes
$x_{GFL}$ exactly. Hence GFL has 11 active states including its PLL, while GFM has 12 active
states including its VSG angle, frequency, and voltage amplitude but no PLL.

The input is
\begin{equation}
u=[P_{ref},Q_{ref},E_{ref}]^T .
\end{equation}
GFL consumes $P_{ref},Q_{ref}$. GFM consumes all three inputs; $E_{ref}$ is an external
terminal-voltage reference, not the measured $|V|$.

\subsection{Per-unit boundary and terminal power}

Let $\kappa=S_{base}/M_{base}$ and let $\vartheta$ be the active controller angle
($\delta_{PLL}$ in GFL or $\theta$ in GFM). The model uses the power-invariant project boundary
\begin{equation}
I_{sys}=\frac{(i_d+\mathrm{j}i_q)e^{\mathrm{j}\vartheta}}{\kappa},\qquad
S_{sys}=P+\mathrm{j}Q=V I_{sys}^{*}.
\label{eq:power-boundary}
\end{equation}
No isolated factor $3/2$ is inserted in only part of the per-unit model. This identity is also the
independent current/power oracle used by tests and reporting adapters.

\section{Common converter plant and dc closure}

With $V e^{-\mathrm{j}\vartheta}=v_d+\mathrm{j}v_q$, limited current
$i_d+\mathrm{j}i_q$, filter parameters $L_f,R_f$, and per-unit frequency $\omega_c$, the common
current plant is
\begin{align}
\frac{L_f}{\omega_b}\dot i_d&=V_{d,del}-v_d-R_f i_d+\omega_cL_f i_q,\\
\frac{L_f}{\omega_b}\dot i_q&=V_{q,del}-v_q-R_f i_q-\omega_cL_f i_d.
\end{align}
The circular limit acts on the controller current reference only.  If
$i^{*,raw}=i_d^{*,raw}+\mathrm{j}i_q^{*,raw}$, then
\begin{equation}
i^*=\alpha i^{*,raw},\qquad
\alpha=\min\!\left(1,\frac{I_{max}}{|i^{*,raw}|}\right).
\end{equation}
The physical filter states $i_d,i_q$ and the terminal-current injection are never projected,
clipped, or replaced by $i^*$. Consequently a fast fault transient may drive actual filter current
above the reference limit; the report discloses that response rather than altering the plant.
The command delay is
\begin{equation}
\dot V_{d,del}=\frac{V_{d,cmd}-V_{d,del}}{T_d},\qquad
\dot V_{q,del}=\frac{V_{q,cmd}-V_{q,del}}{T_d}.
\end{equation}

The physical energy balance requires an external dc current, but the case does not prescribe its
controller. The project therefore uses the declared exogenous controlled-current closure
\begin{align}
I_{dc}&=\frac{P_{ac}}{V_{dc}}+\frac{C_{dc}}{T_{dc}}(V_{dc,ref}-V_{dc}),\\
C_{dc}\dot V_{dc}&=I_{dc}-\frac{P_{ac}}{V_{dc}},\qquad
P_{ac}=V_{d,cmd}i_d+V_{q,cmd}i_q,\\
\therefore\quad \dot V_{dc}&=\frac{V_{dc,ref}-V_{dc}}{T_{dc}}.
\end{align}
Instantaneous power feed-forward prevents this unpublished closure from moving the sourced AC
equilibrium. Nonpositive or nonfinite $V_{dc}$ fails closed.

\section{GFL equations: PLL present}

In the 20-state vector \eqref{eq:xibr}, GFL mode activates the three common-plant states
$i_d,i_q,V_{dc}$ from $x_{GFM}$ together with the eight-state controller $x_{GFL}$ from
\eqref{eq:xgfl}, giving 11 active states, while it freezes the nine GFL-incompatible states
($\theta,\omega,E,\xi_{Vd},\xi_{Vq},\xi_{Id}^{gfm},\xi_{Iq}^{gfm},V_{d,del}^{gfm},V_{q,del}^{gfm}$).
The GFL frame is owned by its PLL:
\begin{align}
v_d+\mathrm{j}v_q&=Ve^{-\mathrm{j}\delta_{PLL}},\\
\dot\xi_{PLL}&=v_q,\\
\dot\delta_{PLL}&=k_{p,PLL}v_q+k_{i,PLL}\xi_{PLL},\\
\omega_{PLL}&=1+\dot\delta_{PLL}/\omega_b.
\end{align}
Measured inverter-base power is $P_{inv}=\kappa P$ and $Q_{inv}=\kappa Q$. The outer loops are
\begin{align}
e_P&=\kappa P_{ref}-P_{inv}, & \dot\xi_P&=e_P,
&i_d^*&=k_{pP}e_P+k_{iP}\xi_P,\\
e_Q&=\kappa Q_{ref}-Q_{inv}, & \dot\xi_Q&=e_Q,
&i_q^*&=-(k_{pQ}e_Q+k_{iQ}\xi_Q).
\end{align}
After circular limitation of $i_d^*+\mathrm{j}i_q^*$, the inner current errors are
$e_d=i_d^*-i_d$ and $e_q=i_q^*-i_q$, and
\begin{align}
V_{d,cmd}&=v_d+R_fi_d-\omega_{PLL}L_fi_q+k_{pI}e_d+k_{iI}\xi_{Id},\\
V_{q,cmd}&=v_q+R_fi_q+\omega_{PLL}L_fi_d+k_{pI}e_q+k_{iI}\xi_{Iq}.
\end{align}
Let $r_d=i_d^{*,raw}-i_d^*$ and $r_q=i_q^{*,raw}-i_q^*$. Anti-windup belongs to the outer
$P/Q$ integrators because their output is the limited current reference:
\begin{align}
\dot\xi_P&=\begin{cases}0,&\alpha<1\ \text{and}\ k_{iP}e_Pr_d>0,\\e_P,&\text{otherwise},\end{cases}\\
\dot\xi_Q&=\begin{cases}0,&\alpha<1\ \text{and}\ (-k_{iQ})e_Qr_q>0,\\e_Q,&\text{otherwise}.\end{cases}
\end{align}
The inner current controller has no voltage-command limiter in this model, hence
$\dot\xi_{Id}=e_d$ and $\dot\xi_{Iq}=e_q$ without the outer-loop hold condition.

\section{GFM equations: VSG angle, no PLL}

In the 20-state vector \eqref{eq:xibr}, GFM mode activates all 12 states of $x_{GFM}$ from
Equation \eqref{eq:xgfm} and freezes the eight-state GFL controller $x_{GFL}$ from
Equation \eqref{eq:xgfl}. GFM owns an absolute virtual-machine angle and frequency:
\begin{align}
\dot\theta&=\omega_b(\omega-1),\\
M\dot\omega&=\kappa P_{ref}-P_{inv}-D_v(\omega-1),\\
\tau_E\dot E&=k_Q(\kappa Q_{ref}-Q_{inv})-k_E(E-E_{ref}).
\label{eq:gfm-e}
\end{align}
Equation~\eqref{eq:gfm-e} is the decisive correction. Replacing $E_{ref}$ by measured $|V|$
would remove the intended external voltage-restoration term at equilibrium and changes the
small-signal physics. The voltage reference is
\begin{equation}
v_d^*=E,\qquad v_q^*=0,\qquad
i_d^*=k_{pV}(v_d^*-v_d)+k_{iV}\xi_{Vd},\qquad
i_q^*=k_{pV}(v_q^*-v_q)+k_{iV}\xi_{Vq}.
\end{equation}
The limited current reference then enters the same physically signed inner current controller and
command-delay plant. Here the limiter-owning states are the voltage-loop integrators:
\begin{equation}
\dot\xi_{Vd}=\begin{cases}0,&\alpha<1\ \text{and}\ k_{iV}e_{Vd}r_d>0,\\e_{Vd},&\text{otherwise},\end{cases}
\quad
\dot\xi_{Vq}=\begin{cases}0,&\alpha<1\ \text{and}\ k_{iV}e_{Vq}r_q>0,\\e_{Vq},&\text{otherwise}.\end{cases}
\end{equation}
The inner states still satisfy $\dot\xi_{Id}=e_d$, $\dot\xi_{Iq}=e_q$. No PLL state or hidden
PLL angle is used in this branch.

\section{Equilibrium, references, and SSSA}

At SG trip the full nonlinear equilibrium solves every rectangular KCL row,
\begin{equation}
YV-I_{inj}(x,V,u)=0,
\end{equation}
plus one $\dot E=0$ equation per selected GFM. Terminal GFM reactive power is a solved output;
$Q_{ref}$ and $E_{ref}$ remain immutable case/event inputs. One scalar active-power mismatch is
distributed by the frozen participation contract. A newly forming GFM holds its pre-trip
$P_{ref}$ when GFL resources remain; those GFL resources share the lost-SG deficit by $P_{max}$.
If every IBR is GFM, the generic post-trip participation is used because no GFL remains.

One angle coordinate per energized island is removed as a mathematical gauge. This does not mean
that only one physical GFM may operate. Several GFMs may form the same island, but they share one
common rotational invariance. SSSA retains all relative electromechanical and controller modes and
quotients only that common VSG-angle direction; no eigenvalue is deleted after calculation.

\section{How the number of GFMs is selected}

For SG-off operation the automatic selector enumerates $n_{GFM}=1,2,3,4$, every subset of that
size, and every admissible reference member. Each candidate must pass topology, full-KCL
equilibrium, operating limits, and the physical SSSA margin $\Omega\le-\gamma_{req}$.
The frozen ranking is: feasible first, fewer event-left mode changes, fewer GFMs, larger damping
margin, deterministic resource-ID tie-break. Thus the current policy means
\emph{minimum small-signal-feasible formation}, not maximum transient robustness.

For the corrected case, local SSSA admits both a one-GFM point and the four-GFM point. The TDS
answers the operationally relevant question: after SG trip the one-GFM formation did not provide
enough large-disturbance support, so live $J_V/J_f$ severity automatically raised the system to
four GFMs. The report therefore presents the four-GFM spectrum below. The one-GFM and all
candidate details remain audit artifacts, not presentation tables. This distinction is important:
local small-signal feasibility is necessary evidence but is not proof of fault/load-step survival.

\subsection{Complete selector and SSSA mode inventory}

All 15 SG-off candidates remain generated and retained for audit. Failed candidates are never
discarded or promoted to readiness, but the long candidate table is omitted from the report.

For a physical decision matrix $A_p$, right eigenvectors $R$ and the paired left-eigenvector rows
$L$ satisfy
\begin{equation}
A_pR=R\Lambda,\qquad L=R\backslash I,\qquad
\pi_{ki}=\frac{|R_{ki}L_{ik}|}{\sum_j|R_{ji}L_{ij}|}.
\end{equation}
Participation is a reporting diagnostic and never feeds candidate ranking.
Each complex-conjugate pair is printed once, with modal frequency
$f_i=|\Im\lambda_i|/(2\pi)$ and damping ratio
$\zeta_i=-\Re\lambda_i/|\lambda_i|$. For readability, each row shows only the mode number,
eigenvalue, frequency, and the single largest-participation device:state. For repeated roots,
especially the four exact $-10$~s$^{-1}$ dc-link
roots, individual eigenvectors may rotate inside the repeated eigenspace; they should be
interpreted as one dc-link family rather than four uniquely attributable modes.

\subsubsection*{Disturbance-support point: four GFMs}

Four 12-state GFMs give 48 full active states and 47 physical decision modes after the same one-angle
quotient. The table has 30 rows with conjugate pairs printed once. No PLL state exists in this
configuration. The limiting root is the real mode $-2.344851$~s$^{-1}$, dominated by GFM voltage-loop
integrators, while the principal VSG angle/frequency families appear at approximately
17.97--23.95~Hz.

\subsection{SG-online 16-subset decision table}

After SG1 is online, it owns the island's numerical angle gauge, but the four IBRs may still
provide physical GFM support. All $2^4=16$ IBR mode subsets are retained in the evidence table;
failed or unstable rows are not deleted. The decision eigenproblem first removes exactly one
rigid network-angle coordinate, then calls \texttt{eig}; its finite-difference robustness check
uses $0.5$, $1$, and $2$ times the frozen Jacobian perturbation. The least-damped result across
those three calculations is $\Omega_{worst}$. A release is possible only when the exact one-IBR
target row is authenticated and robustly stable.

The full 16-row SG-online classification remains an audit artifact rather than a report table.
It explains why ``one GFM or four GFMs'' is not a manual binary choice. Four GFMs give
distributed voltage-forming participation during the disturbance. Once SG1 is back and the live
severity has recovered, the supervisor releases only one GFM at a time. It stops at the smallest
stable subset supported by the table; it does not force all-GFL merely because SG1 is online.

\section{Hybrid event and integration contract}

At a mode transaction, the device reset map preserves the terminal port
$(V,I,P,Q)$ and $V_{dc}$, initializes only the target controller states, then solves the exact
right-limit full-KCL algebraic system. A failure rolls the whole transaction back. Reference
ownership is a numerical/supervisory gauge label, not a physical power injection; changing that
label never replaces, removes, or changes a KCL row.

Normal continuous steps use coupled implicit trapezoidal integration:
\begin{equation}
x_{k+1}-x_k-\frac{h}{2}\left[f(x_k,y_k)+f(x_{k+1},y_{k+1})\right]=0,\qquad
g(x_{k+1},y_{k+1})=0.
\end{equation}
After a discontinuity, only the first interval is restarted with two backward-Euler half steps,
\begin{equation}
x_{m+1}-x_m-\frac{h}{2}f(x_{m+1},y_{m+1})=0,
\end{equation}
before returning to trapezoidal integration. This Rannacher restart damps the nonphysical
step-to-step ringing of a stiff trapezoidal discretisation; it does not smooth, clip, or modify the
physical trajectory.

If a logical output step requires dyadic subdivision, the next logical step starts from the most
recently accepted subdivision level and then coarsens when the full step becomes feasible again.
Every leaf still solves the identical implicit residual with the identical Newton tolerance. This
history is only an initial step-partition choice: it changes neither the differential/algebraic
equations nor the acceptance gate, and avoids repeatedly retrying coarse ancestors already known
to fail in the fault and handback transients.

The per-device severity used for release contains exactly the requested voltage and frequency
terms:
\begin{equation}
J_{V,i}=\frac{\bigl||V_i|-|V_{i,healthy}|\bigr|}{0.10},\qquad
J_f=\frac{|f_{COI}-60|}{0.50},\qquad
S_i=\operatorname{sat}_{[0,1]}\!\left(0.5J_{V,i}+0.5J_f\right).
\end{equation}
The healthy voltage is the case-defined SG-online PF value at that IBR bus. RoCoF, active-power
error, SCR, PLL-lock, and reference-availability diagnostics do not enter this scalar severity;
applicable hard admissibility checks remain separate.

While the SG is offline the same two-term signal is evaluated in real time. If the system severity
remains at or above $\Gamma_{on}=0.65$ for $T_{d,on}=0.10$~s, the selector commits the smallest
authenticated feasible strict superset of the present GFM set. If it remains below
$\Gamma_{off}=0.35$ for $T_{d,off}=1.00$~s, it may commit a feasible subset, but at least one GFM
and one authenticated island reference are retained. In the generated run, SG trip initially
committed one GFM and the measured stress added three resources at 21.2~s; this is an event-driven
one-to-four transition, not a manual four-GFM schedule.

The breaker-open SG is synchronized to the live GFM-formed grid rather than to nominal zero slip.
With $T_e=0$, define
\begin{align}
2H\dot\omega_{SG}&=P_m-D\omega_{SG}, & \dot\delta_{SG}&=\omega_0\omega_{SG},\\
e_\theta&=\operatorname{wrap}(\angle V_{bus}-\angle V_{SG,oc}), &
e_\omega&=\omega_g-\omega_{SG}.
\end{align}
The project-derived mechanical command is
\begin{align}
P_c&=\operatorname{sat}_{[0,P_{max}]}
\left(D\omega_g+K_\omega e_\omega+K_\theta e_\theta\right),\\
K_\omega&=4H\zeta\omega_n-D,\qquad
K_\theta=\frac{2H\omega_n^2}{\omega_0},\\
T_{sv}\dot P_{sv}&=-P_{sv}+P_c,\qquad
T_{ch}\dot P_m=-P_m+P_{sv},
\end{align}
with $\omega_n=0.8$~rad/s, $\zeta=1$, $T_{sv}=0.2$~s, and $T_{ch}=0.4$~s. The voltage matcher
acts separately on field input. The close request at 145~s is only the earliest allowed time; the
case provides a 20-s synchronization opportunity and retains the unchanged 0.5-s dwell. The
breaker closed at \RunReclose~s with
$\Delta V=\RunSyncDV$~pu, $\Delta f=\RunSyncDF$~pu, and
$\Delta\theta=\RunSyncDTheta^\circ$.

Synchronism alone does not guarantee a mild electrical close. Before committing the breaker, the
runtime also evaluates the prospective closed-breaker SG stator current, $P$, $Q$, electrical
power, torque mismatch, controller derivatives, and declared current/apparent-power ratings from
the accepted breaker-left state. Missing or nonfinite evidence, or a rating violation, fails
closed. No SG flux state, physical IBR current state, or network voltage is reset to manufacture a
small jump. At the accepted close the prospective audit reported
$|I|=\RunProsI$~pu against \RunProsImax~pu, $(P,Q)=(\RunProsP,\RunProsQ)$~pu,
$|S|=\RunProsS$~pu against \RunProsSmax~pu, and torque mismatch
\RunProsTorque~pu.

The previous implementation applied the entire pre-event command vector at the breaker instant.
That was a software defect: it combined a physical breaker action with an unrelated controller
command step. The corrected transaction keeps $u(t_c^+)=u(t_c^-)$ and transfers the SG
governor/exciter targets and IBR $P/Q$ targets after closing with
\begin{align}
s(\tau)&=3\tau^2-2\tau^3,\qquad
\tau=\operatorname{sat}_{[0,1]}\!\left(\frac{t-t_c}{T_{hb}}\right),\\
u(t)&=u^-+s(\tau)(u^{target}-u^-),\\
T_{hb}&=\max\!\left[T_{minimum,hold},
\frac{\ln(1/\rho)}{-\Omega_{worst}},
-\ln(\rho)\max(T_{sv},T_{ch},T_A)\right],\quad \rho=0.05.
\end{align}
The cubic has zero slope at both endpoints. If the authenticated physical pole is missing or
nonnegative, support is retained and the transfer fails closed. In the accepted run the derived
transfer lasts \RunHandbackDuration~s and completes at \RunHandbackComplete~s.

The post-reclose handback is not an all-device hard-coded command. SG must first pass the
synchronism and prospective-close guards, after which the C1 participation transfer must finish.
Thereafter each remaining GFM independently requires $S_i<\Gamma_{off}$ for $T_{d,off}$ and an
authenticated robust SG-online one-step target, followed by its own transfer and KCL transaction.
The generated run records candidate releases at \RunReleaseOne, \RunReleaseTwo,
\RunReleaseThree, and \RunReleaseFour~s. The terminal state retains \RunFinalGFMCount{} GFM
resource(s) at bus(es) \RunFinalGFMBuses; an unavailable fourth release is a deliberate
fail-closed outcome, not a hard-coded mode schedule.

\section{Verification and reproduction}

Independent targeted verification covers: fixed state ownership; GFL PLL sensitivity; GFM
no-PLL angle ownership; the exact $E_{ref}$ coefficient in~\eqref{eq:gfm-e}; dc restoration;
terminal-port continuity; per-unit power covariance; source-model SCR applicability; full-KCL
equilibrium; physical SSSA and its SG-online angle quotient; finite-difference robustness;
default trapezoidal equivalence; backward-Euler closed-form behavior; prospective closing;
event rollback; C1 participation transfer; SG reclose; and authenticated one-at-a-time handback.
In the broad 16-file gate, 162/163 tests initially passed. The sole failure exposed a legacy
caller that omitted an owner even though exactly one SG was online; the compatibility path now
infers only that unique owner, and the affected 10/10 tests pass. The full repository suite was
intentionally omitted under the repository risk policy; the targeted set covers the changed
producer, consumers, independent oracles, and event failure paths.

Reproduction commands are:
\begin{verbatim}
matlab -batch "addpath('scripts/reporting'); ...
  generate_gfl_gfm_sssa_tables"
matlab -batch "addpath('scripts/diagnostics'); ...
  run_ieee14_gfl_gfm_state_release"
matlab -batch "addpath('scripts/reporting'); ...
  generate_ieee14_switch_report_figures(reuse_cache=true)"
matlab -batch "addpath('scripts/reporting'); ...
  generate_ieee14_handback_comparison"
\end{verbatim}
The first command rebuilds the authenticated selector and all SSSA tables. The second command
writes continuous progress and the complete transient result to:
\begin{itemize}
\item \path{output/diagnostics/engine_release_progress.log}
\item \path{output/diagnostics/engine_release_result.log}
\item \path{output/diagnostics/engine_release_result.mat}
\end{itemize}
The third command regenerates the trajectory figures, event table, and numerical macros. The
fourth produces the raw before/after metrics and overlay without feeding either production run.

\section{Limitations}

\begin{itemize}
\item The dc-source controller is a declared project-derived closure because the case does not
prescribe the external dc current law.
\item The automatic selector is exhaustive only for at most four eligible IBRs. Larger systems
fail closed pending a validated scalable search.
\item Candidate feasibility includes full $P/Q$ balance and local operating limits at equilibrium,
but it does not yet include a time-domain reserve/security score in its ranking.
\item The model is balanced positive-sequence. Unbalanced and switching-frequency behavior is
outside scope.
\item Transient voltage oscillation is reported honestly and is not a readiness claim.
\end{itemize}
