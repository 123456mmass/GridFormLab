\large สมการ full-state ที่แก้ไขแล้ว การเลือกจำนวน GFM อัตโนมัติ และลำดับเหตุการณ์ 250 วินาที}

\begin{abstract}
รายงานนี้อธิบายแบบจำลองที่แก้ไขแล้วสำหรับ synchronous generator (SG) แบบ EMF6 หนึ่งตัวและ
inverter-based resource (IBR) แบบสลับโหมดได้สี่ตัว ประเด็นหลักคือคืนความเป็นเจ้าของตัวควบคุมให้ตรง
ตามฟิสิกส์: GFL มี phase-locked loop (PLL) ส่วน GFM สร้างมุมด้วย virtual swing equation และไม่มี PLL
ทั้งสองโหมดใช้ state กระแสตัวกรองและ dc link ร่วมกัน การรันที่ร้องขอใช้ $\Delta t=0.1$~s มีเหตุการณ์ที่
20, 50, 85, 85.15, 110 และ 145~s และขยายเวลาสังเกตผลถึง 250~s trajectory ล่าสุดที่สร้างยอมรับได้ถึง
\RunEnd~s ช่วงแรงดันทุกบัสเท่ากับ \RunVMin--\RunVMax~pu และช่วงความถี่รวมเท่ากับ
\RunFMin--\RunFMax~Hz ค่าสูงสุด/ต่ำสุดเหล่านี้เป็นผลที่รายงาน ไม่ใช่ threshold ที่นำไปปรับแต่งแบบจำลอง
residual สูงสุดของ accepted step คือ \RunResidual, subdivision ลึกสุด \RunSubdivision ชั้น และมี
domain-rejected trial \RunDomainRejects ครั้ง SG reclose สำเร็จที่ \RunReclose~s หลัง release แบบทีละตัว
ระบบคง GFM ที่ผ่านหลักฐานไว้ \RunFinalGFMCount{} ตัว ณ บัส \RunFinalGFMBuses{} เพราะ candidate all-GFL
เมื่อ SG online ไม่เสถียรใน small-signal spectrum ผล numerical completion และ operational readiness
จึงถูกรายงานแยกกัน และไม่มีการซ่อน transient หรือนำผลไปจูน gate
\end{abstract}

\section{สัญญา state และ input ที่แก้ไขแล้ว}

IBR แต่ละตัวเก็บเวกเตอร์ 20 state ขนาดคงที่ เพื่อให้อ่านง่าย รายงานใช้ permutation คงที่จัด
GFM/plant block ไว้ก่อน GFL-control block
\begin{align}
x_{IBR}&=\begin{bmatrix}x_{GFM}\\ x_{GFL}\end{bmatrix}
=\Pi\,x_{runtime},
\label{eq:xibr-th}\\[4pt]
x_{GFM}&=\begin{bmatrix}i_d,\,i_q,\,V_{dc},\,\theta,\,\omega,\,E,\,
\xi_{Vd},\,\xi_{Vq},\,\xi_{Id}^{gfm},\,\xi_{Iq}^{gfm},\,
V_{d,del}^{gfm},\,V_{q,del}^{gfm}\end{bmatrix}^{\!T},
\label{eq:xgfm-th}\\[4pt]
x_{GFL}&=\begin{bmatrix}\delta_{PLL},\,\xi_{PLL},\,\xi_P,\,\xi_Q,\,
\xi_{Id}^{gfl},\,\xi_{Iq}^{gfl},\,V_{d,del}^{gfl},\,V_{q,del}^{gfl}\end{bmatrix}^{\!T}.
\label{eq:xgfl-th}
\end{align}
$\Pi$ เป็น reporting-only permutation เท่านั้น production code ยังเก็บ state ตาม ABI เดิมและไม่ได้

\subsection{ขอบเขตเปอร์ยูนิตและกำลังที่ขั้ว}

ให้ $\kappa=S_{base}/M_{base}$ และ $\vartheta$ เป็นมุมของ branch ที่ active สัญญาเปอร์ยูนิตคือ
\begin{equation}
I_{sys}=\frac{(i_d+\mathrm{j}i_q)e^{\mathrm{j}\vartheta}}{\kappa},\qquad
S_{sys}=P+\mathrm{j}Q=V I_{sys}^{*}.
\label{eq:power-th}
\end{equation}
จึงไม่ใส่ factor $3/2$ เฉพาะบางส่วนของแบบจำลอง เพราะจะทำให้ current/power/base ไม่ตรงกัน

\section{plant ร่วมและ dc-link controller}

เมื่อ $Ve^{-\mathrm{j}\vartheta}=v_d+\mathrm{j}v_q$ สมการกระแสตัวกรองคือ
\begin{align}
\frac{L_f}{\omega_b}\dot i_d&=V_{d,del}-v_d-R_fi_d+\omega_cL_fi_q,\\
\frac{L_f}{\omega_b}\dot i_q&=V_{q,del}-v_q-R_fi_q-\omega_cL_fi_d,\\
\dot V_{d,del}&=(V_{d,cmd}-V_{d,del})/T_d,\\
\dot V_{q,del}&=(V_{q,cmd}-V_{q,del})/T_d.
\end{align}
current limit เป็นวงกลมและจำกัดเฉพาะ current reference ของ controller โดยกำหนด
\begin{equation}
i^*=\alpha i^{*,raw},\qquad
\alpha=\min\!\left(1,\frac{I_{max}}{|i^{*,raw}|}\right).
\end{equation}
state กระแสตัวกรองจริง $i_d,i_q$ และ terminal-current injection ไม่ถูก project, clip หรือแทนด้วย $i^*$
ดังนั้นช่วง fault ที่เปลี่ยนเร็วกระแสตัวกรองจริงอาจ overshoot สูงกว่า reference limit ได้ นี่คือผลของ plant
ที่รายงานตามจริง ไม่ใช่เหตุให้ตัด state กระแสออกจากสมการ

case ไม่ได้กำหนดกฎของแหล่งกระแส DC ภายนอก โครงการจึงใช้ closure ที่ประกาศชัดเจน
\begin{align}
I_{dc}&=\frac{P_{ac}}{V_{dc}}+\frac{C_{dc}}{T_{dc}}(V_{dc,ref}-V_{dc}),\\
C_{dc}\dot V_{dc}&=I_{dc}-\frac{P_{ac}}{V_{dc}},\qquad
P_{ac}=V_{d,cmd}i_d+V_{q,cmd}i_q,\\
\therefore\quad \dot V_{dc}&=(V_{dc,ref}-V_{dc})/T_{dc}.
\end{align}
พจน์ feed-forward กำลังทันทีทำให้ closure นี้ไม่เลื่อน equilibrium ของ controller ฝั่ง AC และค่า
$V_{dc}\le0$ หรือไม่ finite จะ fail closed

\section{สมการ GFL: มี PLL}

ในเวกเตอร์ 20 state ของ \eqref{eq:xibr-th} โหมด GFL จะ activate common-plant states สามตัว
$i_d,i_q,V_{dc}$ จาก $x_{GFM}$ ร่วมกับ controller $x_{GFL}$ แปดตัวจาก \eqref{eq:xgfl-th}
รวม 11 active states และ freeze อีกเก้าตัวที่เป็น GFM-only ($\theta,\omega,E,\xi_{Vd},\xi_{Vq},
\xi_{Id}^{gfm},\xi_{Iq}^{gfm},V_{d,del}^{gfm},V_{q,del}^{gfm}$)
กรอบ $dq$ ของ GFL ถูกกำหนดโดย PLL
\begin{align}
v_d+\mathrm{j}v_q&=Ve^{-\mathrm{j}\delta_{PLL}},\\
\dot\xi_{PLL}&=v_q,\\
\dot\delta_{PLL}&=k_{p,PLL}v_q+k_{i,PLL}\xi_{PLL},\\
\omega_{PLL}&=1+\dot\delta_{PLL}/\omega_b.
\end{align}
กำลังบนฐานอุปกรณ์คือ $P_{inv}=\kappa P$ และ $Q_{inv}=\kappa Q$ outer loop เป็น
\begin{align}
e_P&=\kappa P_{ref}-P_{inv},&\dot\xi_P&=e_P,&i_d^*&=k_{pP}e_P+k_{iP}\xi_P,\\
e_Q&=\kappa Q_{ref}-Q_{inv},&\dot\xi_Q&=e_Q,&i_q^*&=-(k_{pQ}e_Q+k_{iQ}\xi_Q).
\end{align}
หลังจำกัด $i_d^*+\mathrm{j}i_q^*$ ให้ $e_d=i_d^*-i_d$ และ $e_q=i_q^*-i_q$ แล้ว
\begin{align}
V_{d,cmd}&=v_d+R_fi_d-\omega_{PLL}L_fi_q+k_{pI}e_d+k_{iI}\xi_{Id},\\
V_{q,cmd}&=v_q+R_fi_q+\omega_{PLL}L_fi_d+k_{pI}e_q+k_{iI}\xi_{Iq}.
\end{align}
ให้ $r_d=i_d^{*,raw}-i_d^*$ และ $r_q=i_q^{*,raw}-i_q^*$ anti-windup ต้องอยู่ที่ integrator ของ
outer $P/Q$ loop เพราะ output ของ loop นี้คือ current reference ที่ถูกจำกัด
\begin{align}
\dot\xi_P&=\begin{cases}0,&\alpha<1\ \text{และ}\ k_{iP}e_Pr_d>0,\\e_P,&\text{กรณีอื่น},\end{cases}\\
\dot\xi_Q&=\begin{cases}0,&\alpha<1\ \text{และ}\ (-k_{iQ})e_Qr_q>0,\\e_Q,&\text{กรณีอื่น}.\end{cases}
\end{align}
เครื่องหมาย $-k_{iQ}$ มาจากนิยาม $i_q^{*,raw}=-(k_{pQ}e_Q+k_{iQ}\xi_Q)$ ไม่ใช่การเดาเครื่องหมาย
ส่วน inner current PI ไม่มี voltage-command limiter แยกในแบบจำลองนี้ จึงต้องมี
$\dot\xi_{Id}=e_d$ และ $\dot\xi_{Iq}=e_q$ ตามปกติ ไม่ใช้ hold ของ outer loop

\section{สมการ GFM: มุม VSG และไม่มี PLL}

ในเวกเตอร์ 20 state ของ \eqref{eq:xibr-th} โหมด GFM จะ activate $x_{GFM}$ ทั้ง 12 ตัวตาม
Equation~\eqref{eq:xgfm-th} และ freeze controller $x_{GFL}$ แปดตัวตาม Equation~\eqref{eq:xgfl-th}
GFM สร้างมุมและความถี่ของตนเอง
\begin{align}
\dot\theta&=\omega_b(\omega-1),\\
M\dot\omega&=\kappa P_{ref}-P_{inv}-D_v(\omega-1),\\
\tau_E\dot E&=k_Q(\kappa Q_{ref}-Q_{inv})-k_E(E-E_{ref}).
\label{eq:gfm-e-th}
\end{align}
สมการ~\eqref{eq:gfm-e-th} คือจุดแก้หลัก การใช้ $|V|$ ที่วัดได้แทน $E_{ref}$ จะตัดพจน์คืนแรงดัน
ภายนอกที่ equilibrium และเปลี่ยนฟิสิกส์ small-signal voltage reference ของ voltage loop คือ
\begin{equation}
v_d^*=E,\qquad v_q^*=0,\qquad
i_d^*=k_{pV}(v_d^*-v_d)+k_{iV}\xi_{Vd},\qquad
i_q^*=k_{pV}(v_q^*-v_q)+k_{iV}\xi_{Vq}.
\end{equation}
current reference ที่ผ่าน limit เข้าสู่ inner current PI และ command-delay plant เดียวกัน สำหรับ GFM
integrator ที่เป็นเจ้าของ anti-windup คือ voltage loop
\begin{equation}
\dot\xi_{Vd}=\begin{cases}0,&\alpha<1\ \text{และ}\ k_{iV}e_{Vd}r_d>0,\\e_{Vd},&\text{กรณีอื่น},\end{cases}
\quad
\dot\xi_{Vq}=\begin{cases}0,&\alpha<1\ \text{และ}\ k_{iV}e_{Vq}r_q>0,\\e_{Vq},&\text{กรณีอื่น}.\end{cases}
\end{equation}

สมการ gain มาจากการวาง pole ของ relative angle/speed pair ที่ได้จาก swing equation ของโครงการเอง
โดยใช้ $\omega_n=0.8$~rad/s, $\zeta=1$, $T_{sv}=0.2$~s และ $T_{ch}=0.4$~s
ส่วน voltage matcher ปรับ field input แยกจาก mechanical synchronizer linearization ที่รวม actuator lag
ทั้งสองให้ eigenvalue ทุกตัวอยู่ซีกซ้ายและ $\max\Re(\lambda)<-0.5$~s$^{-1}$

คำขอ $sg\_on=145$~s เป็นเวลาเริ่มอนุญาต ไม่ใช่คำสั่งปิด breaker ทันที case ให้โอกาส synchronizer
20~s โดยไม่เปลี่ยน threshold หรือ dwell 0.5~s ผลจริงปิดที่ \RunReclose~s และ guard ขณะปิดคือ
\begin{equation}
\Delta V=\RunSyncDV~\text{pu},\qquad
\Delta f=\RunSyncDF~\text{pu},\qquad
\Delta\theta=\RunSyncDTheta^\circ.
\end{equation}
ทุกค่าผ่านกรอบเดิมก่อนทำ atomic right-limit KCL transaction แล้ว reference owner จึงย้ายกลับ SG
โดยที่โหมด IBR ยังไม่เปลี่ยนใน transaction นี้

\subsection{prospective-close audit: ผ่าน synchronism แล้วยังต้องตรวจอะไร}

การที่แรงดัน ความถี่ และมุมอยู่ใน synchronism band ยังไม่รับประกันว่ากระแสตอนปิด breaker จะเล็ก
เพราะ SG มี flux states ภายในและ stator algebraic equations ของตนเอง ก่อน commit จึงสร้างบริบท
``สมมติว่าปิด breaker'' จาก accepted breaker-left $(x^-,y^-,u^-)$ แล้วคำนวณโดยไม่แก้ state ว่า
\begin{equation}
I_{SG}^{pros},\quad P_{SG}^{pros},\quad Q_{SG}^{pros},\quad P_e^{pros},\quad
P_m-P_e^{pros},\quad P_{sv}-P_m,
\end{equation}
รวมถึง derivative ของ flux/exciter และ apparent power
$|S_{SG}^{pros}|=\sqrt{(P_{SG}^{pros})^2+(Q_{SG}^{pros})^2}$ ค่าเหล่านี้ต้อง finite และไม่เกิน
current/apparent-power rating ที่ประกาศ ถ้าหลักฐานขาดหรือเกิน limit จะไม่ปิด breaker

จุดสำคัญคือ audit นี้ไม่ reset physical state เพื่อทำให้ผลดูดี: ไม่ตั้ง flux ใหม่, ไม่ clip $i_d,i_q$,
ไม่แก้ bus voltage และไม่ bypass KCL กระแสหลังปิดไม่จำเป็นต้องเป็นศูนย์ แต่ต้องเป็นค่าที่สมการ stator
และ rating รองรับได้ วิธีนี้แยกชัดระหว่าง ``ปิดได้ทาง synchronism'' กับ ``ปิดแล้วไม่สร้าง electrical shock
เกินขอบเขตที่ประกาศ''

ค่าที่ accepted close คือ $|I|=\RunProsI$~pu เทียบ limit \RunProsImax~pu,
$(P,Q)=(\RunProsP,\RunProsQ)$~pu, $|S|=\RunProsS$~pu เทียบ rating \RunProsSmax~pu และ
torque mismatch \RunProsTorque~pu ตัวเลขนี้มาจาก breaker-left state จริง ไม่ใช่ค่าที่ตั้งให้ผ่าน

\subsection{บัค command step เดิมและ C1 participation handback}

ผล baseline เดิมไม่ได้แกว่งแรงเพราะฟิสิกส์อย่างเดียว ที่ breaker close โค้ดเดิมกำหนด
$u^+=u^{pre-event}$ ทั้งเวกเตอร์ ทำให้คำสั่ง mechanical/excitation ของ SG และ $P/Q$ reference ของ IBR
กระโดดพร้อมกัน infinity norm ของ command jump เท่ากับ \CmpBaselineDU{} นี่เป็น implementation bug:
breaker closure มีสิทธิ์เปลี่ยน topology แต่ไม่มีเหตุผลทางฟิสิกส์ให้ reset controller command ทุกตัวใน instant เดียว

โค้ดที่แก้แล้วรักษา
\begin{equation}
u(t_c^+)=u(t_c^-)
\end{equation}
และค่อยเปลี่ยน SG governor/exciter target กับ IBR $P/Q$ target ด้วย cubic smoothstep
\begin{align}
s(\tau)&=3\tau^2-2\tau^3, &
\tau&=\operatorname{sat}_{[0,1]}\left(\frac{t-t_c}{T_{hb}}\right),\\
u(t)&=u^-+s(\tau)(u^{target}-u^-).
\end{align}
เพราะ $s(0)=0$, $s(1)=1$ และ $s'(0)=s'(1)=0$ คำสั่งจึงต่อเนื่องและไม่มี slope kick ที่หัว/ท้าย ramp
ระยะเวลาไม่ได้ tune จากกราฟ แต่ derive ก่อนรันจาก robust SG-online pole และ controller time constants
\begin{equation}
T_{hb}=\max\left[
T_{minimum,hold},\frac{\ln(1/\rho)}{-\Omega_{worst}},
-\ln(\rho)\max(T_{sv},T_{ch},T_A)\right],\qquad \rho=0.05.
\end{equation}
ถ้า $\Omega_{worst}\ge0$ หรือหลักฐานไม่ครบ จะคง GFM support และ fail closed แทนการเดาระยะ ramp
ผลรันใช้ $T_{hb}=\RunHandbackDuration$~s และจบ ramp ที่ \RunHandbackComplete~s โดย command jump
ที่ breaker ลดเป็น \CmpImprovedDU

หลัง SG reclose ไม่มีคำสั่ง hard-code ให้ IBR ทุกตัวกลับ GFL พร้อมกัน ลำดับจริงคือ
\begin{enumerate}
\item synchronism และ prospective-close guard ผ่าน;
\item breaker close โดยไม่ reset physical/controller state;
\item C1 participation ramp จบ;
\item $S_i<\Gamma_{off}$ ต่อเนื่องครบ $T_{d,off}$;
\item exact one-step SG-online candidate ผ่าน fingerprint, equilibrium, SSSA, reserve และ headroom;
\item release GFM เพียงหนึ่งตัว แล้ว reset dwell/cooldown ก่อนประเมินรอบใหม่
\end{enumerate}
ผลจริงพิจารณา release ทีละตัวที่ \RunReleaseOne, \RunReleaseTwo, \RunReleaseThree และ
\RunReleaseFour~s สถานะปลายทางยังคง GFM \RunFinalGFMCount{} ตัวที่บัส \RunFinalGFMBuses{}
เพราะการปล่อยตัวสุดท้ายไป all-GFL ไม่ผ่านหลักฐาน SSSA ไม่ใช่เพราะ hard-code ให้เหลือหนึ่งตัว

\section{ข้อจำกัด}

\begin{itemize}
\item dc-source controller เป็น project-derived closure เพราะ case ไม่ได้กำหนดกฎกระแส DC ภายนอก
\item automatic selector แบบ exhaustive ผ่านการตรวจเฉพาะเมื่อ eligible IBR ไม่เกินสี่ตัว ระบบใหญ่กว่านี้ fail closed
จนกว่าจะมี scalable search ที่ตรวจสอบแล้ว
\item candidate feasibility รวมสมดุล $P/Q$ และ limit ที่ equilibrium แต่ ranking ยังไม่มี time-domain reserve/security score
\item แบบจำลองเป็น balanced positive-sequence พฤติกรรม unbalanced และ switching-frequency อยู่นอกขอบเขต
\item transient voltage oscillation ถูกเปิดเผยและไม่ใช่ readiness claim
\end{itemize}
