\begin{abstract}
รายงานนี้เน้น IBR switching โดยตรง ใช้ข้อมูล case จาก
\texttt{docs/text/EECON49\_[Nui].pdf} แต่คงวิธี AGSI++ ของโครงการ ไม่ได้คัดลอกวิธี
Bayesian optimization จากบทความ เพิ่ม grid-reference availability (GRA) เป็นพจน์ที่เจ็ด
และเฉลี่ยน้ำหนักใหม่เป็น $1/7$ เท่ากัน ผลที่ยืนยันได้คือ SG trip ที่ $20$~s ทำให้ IBR
ทั้งสี่ commit GFL$\to$GFM ที่ $20.5$~s พร้อมกันเพราะ local index/dwell ครบเวลาเดียวกัน
ไม่ใช่ broadcast command ส่วน restoration ที่ $145$~s ยังไม่ผ่าน: trajectory ลู่ออกที่
$147.020$~s ภายใต้ reduced model ปัจจุบัน จึงห้ามอ้างว่าจำลอง recovery สำเร็จ
กราฟเป็นข้อมูลดิบ ไม่มี noise, smoothing หรือ clipping
\end{abstract}

\section{ขอบเขตและข้อมูล case}
ระบบ IEEE 14 บัสใช้ฐาน $S_{base}=100$~MVA, $f_0=60$~Hz มี SG ที่บัส~1 และ IBR
ที่บัส~2, 3, 6, 8 ค่าที่นำจาก EECON49 คือ $H=2.5$~s, $D=1.0$~pu และลำดับเหตุการณ์
0--160~s ส่วนสมการ IBR, AGSI++, threshold และ dwell เป็นของโครงการ การเปลี่ยนนี้ไม่แก้
สมการ branch GFL/GFM หรือค่า normalisation และไม่ใช้ external solver

\section{AGSI++ เจ็ดพจน์และความหมายตัวแปร}
\begin{align}
J_V&=\frac{|V-V_{ref}|}{0.10},&
J_f&=\frac{|f-60|}{0.50},&
J_R&=\frac{|\mathrm{d}f/\mathrm{d}t|}{1.0},\\
J_P&=\frac{|P_{ref}-P|}{0.20},&
J_{SCR}&=\max\left(0,\frac{3}{SCR}-1\right),&
J_{lock}&=\frac{|v_q|}{0.10},\\
J_{GRA}&=1-GRA,&
\mathrm{AGSI}^{++}_i&=\frac{1}{7}\sum_{k\in\{V,f,R,P,SCR,lock,GRA\}}J_{k,i}.
\end{align}

\section{เหตุใดควรกลับปกติ แต่ model ยังทำไม่ได้}
ระบบจริงที่ SG/สายกลับ โหลดคืนฐาน และผ่าน synchronism ควรมีเส้นทางกลับ operating point เดิม
แต่แบบจำลองนี้มีข้อจำกัด:
\begin{enumerate}
\item SG เป็น Padiyar model-1.1 ลดรูป สนามคงที่ ไม่มี AVR/PSS และไม่มี governor/turbine
หรือ synchronizer/breaker dynamic states
\item reclose reinitialise SG ที่แรงดัน island ซึ่งตกต่ำ ไม่ได้จำลองการปรับมุม แรงดัน และกำลังก่อนปิด breaker
\item IBR reduced-6 ไม่มี DC-link, energy-source, EMT inner switching และ protection เต็มรูป
\item โหลดใน dynamic route เป็น constant impedance และ trajectory หลัง trip ออกนอกช่วงรับรอง model
\end{enumerate}
ดังนั้นความคาดหวังว่าต้องกลับปกติสมเหตุผล แต่ผลนี้บอกว่า model/reclose contract ยังไม่พอ
ไม่ใช่เหตุผลให้ reset state, เติม noise, จูน parameter หรือซ่อนช่วงลู่ออก งานถัดไปต้องเพิ่ม
synchronised-reclose model และ SG governor/AVR contract จากแหล่งอ้างอิงก่อนอ้าง recovery
