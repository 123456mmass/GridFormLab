\begin{abstract}
รายงานนี้อธิบายแบบจำลองที่แก้ไขแล้วสำหรับ synchronous generator (SG) แบบ EMF6 หนึ่งตัวและ
inverter-based resource (IBR) แบบสลับโหมดได้สี่ตัว ประเด็นหลักคือคืนความเป็นเจ้าของตัวควบคุมให้ตรง
ตามฟิสิกส์: GFL มี phase-locked loop (PLL) ส่วน GFM สร้างมุมด้วย virtual swing equation และไม่มี PLL
ทั้งสองโหมดใช้ state กระแสตัวกรองและ dc link ร่วมกัน การรันที่ร้องขอใช้ $\Delta t=0.1$~s มีเหตุการณ์ที่
20, 50, 85, 85.15, 110 และ 145~s และขอผลถึง 200~s trajectory ล่าสุดที่สร้างยอมรับได้ถึง
\RunEnd~s ช่วงแรงดันทุกบัสเท่ากับ \RunVMin--\RunVMax~pu และช่วงความถี่รวมเท่ากับ
\RunFMin--\RunFMax~Hz ค่าสูงสุด/ต่ำสุดเหล่านี้เป็นผลที่รายงาน ไม่ใช่ threshold ที่นำไปปรับแต่งแบบจำลอง
residual สูงสุดของ accepted step คือ \RunResidual, subdivision ลึกสุด \RunSubdivision ชั้น และมี
domain-rejected trial \RunDomainRejects ครั้ง SG reclose สำเร็จที่ \RunReclose~s และ transaction
คืนโหมดรายอุปกรณ์ครบ all-GFL ที่ \RunFinalRelease~s ผลนี้ยืนยัน numerical completion แต่ช่วงแกว่งที่สูง
ยังไม่อนุญาตให้อ้าง operational readiness
\end{abstract}

\section{สัญญา state และ input ที่แก้ไขแล้ว}

IBR แต่ละตัวเก็บเวกเตอร์ 20 state ขนาดคงที่
\begin{align}
x={}&[i_d,i_q,V_{dc},
\delta_{PLL},\xi_{PLL},\xi_P,\xi_Q,\xi_{Id}^{gfl},\xi_{Iq}^{gfl},V_{d,del}^{gfl},V_{q,del}^{gfl},\nonumber\\
&\theta,\omega,E,\xi_{Vd},\xi_{Vq},\xi_{Id}^{gfm},\xi_{Iq}^{gfm},V_{d,del}^{gfm},V_{q,del}^{gfm}]^T .
\end{align}
$x_{1:3}$ เป็น plant ร่วม โหมด GFL ทำให้ $x_{1:11}$ active และ hold $x_{12:20}$ พอดี ส่วน GFM
ทำให้ $x_{1:3},x_{12:20}$ active และ hold $x_{4:11}$ ดังนั้น GFL มี 11 active states รวม PLL
ขณะที่ GFM มี 12 active states รวมมุม VSG, ความถี่ และ amplitude $E$ แต่ไม่มี PLL
input ภายนอกคงรูปเป็น
\begin{equation}
u=[P_{ref},Q_{ref},E_{ref}]^T .
\end{equation}
GFL ใช้ $P_{ref},Q_{ref}$ ส่วน GFM ใช้ทั้งสามค่า โดย $E_{ref}$ คือ terminal-voltage reference ภายนอก
ไม่ใช่แรงดันที่วัดได้ $|V|$

\subsection{ขอบเขตเปอร์ยูนิตและกำลังที่ขั้ว}

ให้ $\kappa=S_{base}/M_{base}$ และ $\vartheta$ เป็นมุมของ branch ที่ active สัญญาเปอร์ยูนิตคือ
\begin{equation}
I_{sys}=\frac{(i_d+\mathrm{j}i_q)e^{\mathrm{j}\vartheta}}{\kappa},\qquad
S_{sys}=P+\mathrm{j}Q=V I_{sys}^{*}.
\label{eq:power-th}
\end{equation}
จึงไม่ใส่ factor $3/2$ เฉพาะบางส่วนของแบบจำลอง เพราะจะทำให้ current/power/base ไม่ตรงกัน

\section{plant ร่วมและ dc-link controller}

เมื่อ $Ve^{-\mathrm{j}\vartheta}=v_d+\mathrm{j}v_q$ สมการกระแสตัวกรองคือ
\begin{align}
\frac{L_f}{\omega_b}\dot i_d&=V_{d,del}-v_d-R_fi_d+\omega_cL_fi_q,\\
\frac{L_f}{\omega_b}\dot i_q&=V_{q,del}-v_q-R_fi_q-\omega_cL_fi_d,\\
\dot V_{d,del}&=(V_{d,cmd}-V_{d,del})/T_d,\\
\dot V_{q,del}&=(V_{q,cmd}-V_{q,del})/T_d.
\end{align}
current limit เป็นวงกลมและจำกัดเฉพาะ current reference ของ controller โดยกำหนด
\begin{equation}
i^*=\alpha i^{*,raw},\qquad
\alpha=\min\!\left(1,\frac{I_{max}}{|i^{*,raw}|}\right).
\end{equation}
state กระแสตัวกรองจริง $i_d,i_q$ และ terminal-current injection ไม่ถูก project, clip หรือแทนด้วย $i^*$
ดังนั้นช่วง fault ที่เปลี่ยนเร็วกระแสตัวกรองจริงอาจ overshoot สูงกว่า reference limit ได้ นี่คือผลของ plant
ที่รายงานตามจริง ไม่ใช่เหตุให้ตัด state กระแสออกจากสมการ

case ไม่ได้กำหนดกฎของแหล่งกระแส DC ภายนอก โครงการจึงใช้ closure ที่ประกาศชัดเจน
\begin{align}
I_{dc}&=\frac{P_{ac}}{V_{dc}}+\frac{C_{dc}}{T_{dc}}(V_{dc,ref}-V_{dc}),\\
C_{dc}\dot V_{dc}&=I_{dc}-\frac{P_{ac}}{V_{dc}},\qquad
P_{ac}=V_{d,cmd}i_d+V_{q,cmd}i_q,\\
\therefore\quad \dot V_{dc}&=(V_{dc,ref}-V_{dc})/T_{dc}.
\end{align}
พจน์ feed-forward กำลังทันทีทำให้ closure นี้ไม่เลื่อน equilibrium ของ controller ฝั่ง AC และค่า
$V_{dc}\le0$ หรือไม่ finite จะ fail closed

\section{สมการ GFL: มี PLL}

กรอบ $dq$ ของ GFL ถูกกำหนดโดย PLL
\begin{align}
v_d+\mathrm{j}v_q&=Ve^{-\mathrm{j}\delta_{PLL}},\\
\dot\xi_{PLL}&=v_q,\\
\dot\delta_{PLL}&=k_{p,PLL}v_q+k_{i,PLL}\xi_{PLL},\\
\omega_{PLL}&=1+\dot\delta_{PLL}/\omega_b.
\end{align}
กำลังบนฐานอุปกรณ์คือ $P_{inv}=\kappa P$ และ $Q_{inv}=\kappa Q$ outer loop เป็น
\begin{align}
e_P&=\kappa P_{ref}-P_{inv},&\dot\xi_P&=e_P,&i_d^*&=k_{pP}e_P+k_{iP}\xi_P,\\
e_Q&=\kappa Q_{ref}-Q_{inv},&\dot\xi_Q&=e_Q,&i_q^*&=-(k_{pQ}e_Q+k_{iQ}\xi_Q).
\end{align}
หลังจำกัด $i_d^*+\mathrm{j}i_q^*$ ให้ $e_d=i_d^*-i_d$ และ $e_q=i_q^*-i_q$ แล้ว
\begin{align}
V_{d,cmd}&=v_d+R_fi_d-\omega_{PLL}L_fi_q+k_{pI}e_d+k_{iI}\xi_{Id},\\
V_{q,cmd}&=v_q+R_fi_q+\omega_{PLL}L_fi_d+k_{pI}e_q+k_{iI}\xi_{Iq}.
\end{align}
ให้ $r_d=i_d^{*,raw}-i_d^*$ และ $r_q=i_q^{*,raw}-i_q^*$ anti-windup ต้องอยู่ที่ integrator ของ
outer $P/Q$ loop เพราะ output ของ loop นี้คือ current reference ที่ถูกจำกัด
\begin{align}
\dot\xi_P&=\begin{cases}0,&\alpha<1\ \text{และ}\ k_{iP}e_Pr_d>0,\\e_P,&\text{กรณีอื่น},\end{cases}\\
\dot\xi_Q&=\begin{cases}0,&\alpha<1\ \text{และ}\ (-k_{iQ})e_Qr_q>0,\\e_Q,&\text{กรณีอื่น}.\end{cases}
\end{align}
เครื่องหมาย $-k_{iQ}$ มาจากนิยาม $i_q^{*,raw}=-(k_{pQ}e_Q+k_{iQ}\xi_Q)$ ไม่ใช่การเดาเครื่องหมาย
ส่วน inner current PI ไม่มี voltage-command limiter แยกในแบบจำลองนี้ จึงต้องมี
$\dot\xi_{Id}=e_d$ และ $\dot\xi_{Iq}=e_q$ ตามปกติ ไม่ใช้ hold ของ outer loop

\section{สมการ GFM: มุม VSG และไม่มี PLL}

GFM สร้างมุมและความถี่ของตนเอง
\begin{align}
\dot\theta&=\omega_b(\omega-1),\\
M\dot\omega&=\kappa P_{ref}-P_{inv}-D_v(\omega-1),\\
\tau_E\dot E&=k_Q(\kappa Q_{ref}-Q_{inv})-k_E(E-E_{ref}).
\label{eq:gfm-e-th}
\end{align}
สมการ~\eqref{eq:gfm-e-th} คือจุดแก้หลัก การใช้ $|V|$ ที่วัดได้แทน $E_{ref}$ จะตัดพจน์คืนแรงดัน
ภายนอกที่ equilibrium และเปลี่ยนฟิสิกส์ small-signal voltage reference ของ voltage loop คือ
\begin{equation}
v_d^*=E,\qquad v_q^*=0,qquad
i_d^*=k_{pV}(v_d^*-v_d)+k_{iV}\xi_{Vd},\qquad
i_q^*=k_{pV}(v_q^*-v_q)+k_{iV}\xi_{Vq}.
\end{equation}
current reference ที่ผ่าน limit เข้าสู่ inner current PI และ command-delay plant เดียวกัน สำหรับ GFM
integrator ที่เป็นเจ้าของ anti-windup คือ voltage loop
\begin{equation}
\dot\xi_{Vd}=\begin{cases}0,&\alpha<1\ \text{และ}\ k_{iV}e_{Vd}r_d>0,\\e_{Vd},&\text{กรณีอื่น},\end{cases}
\quad
\dot\xi_{Vq}=\begin{cases}0,&\alpha<1\ \text{และ}\ k_{iV}e_{Vq}r_q>0,\\e_{Vq},&\text{กรณีอื่น}.\end{cases}
\end{equation}
inner states ยังคง $\dot\xi_{Id}=e_d$, $\dot\xi_{Iq}=e_q$ ไม่มี PLL state หรือมุม PLL แฝงอยู่ใน branch นี้

\section{equilibrium, reference และ SSSA}

หลัง SG trip ตัวแก้ nonlinear equilibrium ใช้ KCL รูปพิกัดฉากทุกแถว
\begin{equation}
YV-I_{inj}(x,V,u)=0
\end{equation}
ร่วมกับเงื่อนไข $\dot E=0$ หนึ่งสมการต่อ GFM ที่เลือก terminal $Q$ ของ GFM เป็นผลลัพธ์ที่ตัวแก้หา
ส่วน $Q_{ref}$ และ $E_{ref}$ ยังเป็น input ของ case/event

กำลังจริง SG ที่หาย $133.190444$~MW ถูกชดเชยครบ และกำลังรีแอกทีฟที่หาย
$-19.566556$~MVAr ถูกกระจายตาม participation ที่ freeze ก่อน transient ถ้ายังมี GFL เหลือ GFM ที่เพิ่ง
form จะคง $P_{ref}$ ก่อน event เพื่อไม่สร้าง swing kick และ GFL ที่เหลือรับ deficit ตาม $P_{max}$
ถ้า IBR ทั้งหมดเป็น GFM จะต้องใช้ post-trip participation ทั่วไปเพราะไม่เหลือ GFL รับ deficit

หนึ่ง energized island ตัด angle coordinate ร่วมเพียงหนึ่งตัวเพื่อกำหนด gauge ทางคณิตศาสตร์
ไม่ได้แปลว่าอนุญาต GFM ทางกายภาพได้เพียงตัวเดียว หลาย GFM ทำงานร่วมกันได้ แต่มี rotational invariance
ร่วมกันหนึ่งทิศทาง SSSA จึง quotient เฉพาะมุม VSG ร่วมและเก็บ relative modes ทั้งหมดไว้

\section{การเลือกว่าจะใช้ GFM หนึ่งตัวหรือหลายตัว}

เมื่อ SG offline selector แบบ automatic ไล่ครบ $n_{GFM}=1,2,3,4$, ทุก subset และทุก reference ที่เป็น
สมาชิก candidate ต้องผ่าน topology, full-KCL equilibrium, operating limits และ
$\Omega\le-\gamma_{req}$ จาก physical SSSA แล้วจัดลำดับ: feasible ก่อน, จำนวน mode change น้อยกว่า,
จำนวน GFM น้อยกว่า, damping margin มากกว่า และ tie-break ตาม resource ID ดังนั้น policy ปัจจุบันคือ
\emph{minimum small-signal-feasible formation} ไม่ใช่ maximum transient robustness

index ของ composite resource คือ $1=$SG1, $2=$IBR2, $3=$IBR3, $4=$IBR6 และ $5=$IBR8
ดังนั้นเลข 5 ในตารางหมายถึง IBR ที่บัส 8 ไม่ใช่ ``GFM ตัวที่ 5'' จาก 15 candidates มี 2 ชุดที่ผ่าน
\begin{center}
\begin{tabular}{@{}lrrrr@{}}\toprule
resource ที่เลือก & $n_{GFM}$ & reference & $\Omega$ (s$^{-1}$) & KCL norm \\ \midrule
$[5]$ & 1 & 5 & $-0.175750$ & $5.311\times10^{-13}$ \\
$[2,3,4,5]$ & 4 & 2 & $-2.344851$ & $4.025\times10^{-12}$ \\
\bottomrule\end{tabular}
\end{center}
ชุดสี่ GFM มี local damping margin สูงกว่าและกระจาย voltage-forming support หลายบัส แต่ชุดหนึ่ง GFM
เปลี่ยนโหมดน้อยกว่าและทำ active-power handover แบบ bumpless ได้ตาม dispatch ปัจจุบัน SSSA เพียงอย่างเดียว
ยังพิสูจน์ไม่ได้ว่าจะผ่าน disturbance ใหญ่ทั้งหมด จึงต้องใช้ chronology 200~s เป็น falsification test

\section{SSSA แบบละเอียด: จำนวน mode, eigenvalue, ความถี่ และเจ้าของ state}

\subsection{สร้างเมทริกซ์ small-signal อย่างไร}

ให้สมการ DAE รอบ equilibrium ที่ยอมรับแล้วเป็น
\begin{align}
\Delta\dot x &= f_x\Delta x+f_y\Delta y,\\
0&=g_x\Delta x+g_y\Delta y.
\end{align}
เมื่อ $g_y$ มี condition ผ่าน gate จะกำจัดตัวแปรพีชคณิตด้วย linear solve ของโครงการ ได้
\begin{equation}
A_{red}=f_x-f_yg_y^{-1}g_x.
\label{eq:ared-th}
\end{equation}
ในโค้ดไม่ได้สร้าง $g_y^{-1}$ ด้วย \texttt{inv}; ใช้ linear solve ที่ตรวจ residual/conditioning
จากนั้นใช้ fixed-active-set tangent elimination ถ้ามี state ชน limit และตัด rotational gauge ร่วมหนึ่งพิกัด
\emph{ก่อน} เรียก \texttt{eig} จึงไม่มีการคำนวณ eigenvalue แล้วเลือกลบทิ้งภายหลัง

full spectrum หมายถึง eigenvalue ของ active differential states ทั้งหมด ส่วน physical decision spectrum
หมายถึง spectrum หลัง constraint/gauge quotient ที่ใช้ตัดสิน $\Omega=\max\Re\lambda$ กรณี SG offline
ไม่มี SG state อยู่ใน active spectrum เพราะ breaker เปิด แต่ SG state ยังคงเก็บในเวกเตอร์เต็มของ TDS

\subsection{ผล candidate ครบทุกจำนวน GFM}

ตารางถัดไปเก็บ candidate ทั้ง 15 ชุด ไม่ได้แสดงเฉพาะชุดที่ผ่าน เพื่อให้เห็นว่าชุดใดหยุดที่ equilibrium,
ชุดใดไปถึง SSSA และชุดใดมี eigenvalue ด้านขวา ``Eq.'' หมายถึงมีการพยายามแก้ full nonlinear all-KCL
equilibrium ส่วน ``SSSA'' หมายถึงไปถึง full-state linearisation แล้ว candidate ที่ไม่ผ่านยังเป็นหลักฐาน

\subsection{นิยาม modal frequency, damping และ participation}

สำหรับ physical decision matrix $A_p$ ให้ $R$ เป็น right eigenvectors และ $L$ เป็นแถว left eigenvectors
ที่จับคู่กัน โดยคำนวณด้วย linear solve $L=R\backslash I$ ไม่ใช้ \texttt{inv}
\begin{align}
A_pR&=R\Lambda,\\
\pi_{ki}&=\frac{|R_{ki}L_{ik}|}{\sum_j|R_{ji}L_{ij}|},\\
f_i&=\frac{|\Im\lambda_i|}{2\pi},\qquad
\zeta_i=-\frac{\Re\lambda_i}{|\lambda_i|}.
\end{align}
$\pi_{ki}$ ใช้เพื่ออธิบายว่า mode หมายเลข $i$ มี state ใดเข้าร่วมเด่น ไม่ได้ป้อนกลับ selector หรือ gate
ตารางพิมพ์ complex-conjugate pair เพียงแถวเดียว จึงมีจำนวนแถวน้อยกว่าจำนวน physical roots
รูปแบบ IBR8:$E^{GFM}$ แปลว่า state แอมพลิจูด $E$ ของ branch GFM ในอุปกรณ์ IBR8

หาก eigenvalue ซ้ำกัน eigenvectors ภายใน eigenspace หมุนเปลี่ยน basis ได้ ตัวอย่างคือ root
$-10$~s$^{-1}$ ของ $V_{dc}$ ทั้งสี่ตัว จึงต้องอ่านเป็น ``dc-link family สี่ราก'' ไม่ใช่ยืนยันว่า
แถวแรกเป็นของอุปกรณ์ใดโดยเอกลักษณ์ participation ของ root ที่ไม่ซ้ำตีความได้ตรงกว่า

\subsection{ข้อสรุป SSSA ที่ใช้ได้และใช้ไม่ได้}

จาก SSSA กล่าวได้ว่าทั้ง configuration 1 และ 4 GFM เป็น local asymptotically stable รอบ equilibrium
ที่แก้ full $P/Q$ balance แล้ว และ configuration 4 GFM มี local damping margin สูงกว่า
แต่ยังกล่าวไม่ได้ว่า 4 GFM จะผ่าน transient ดีกว่าเสมอ เพราะ dispatch ตอน SG trip ต่างกัน:

\section{event transaction และตัวอินทิเกรต}

เมื่อสลับโหมด reset map รักษา terminal port $(V,I,P,Q)$ และ $V_{dc}$, initialize เฉพาะ controller
ของโหมดเป้าหมาย แล้วแก้ right-limit full-KCL ถ้าขั้นใดไม่ผ่าน transaction ทั้งก้อน rollback
reference ownership เป็นบทบาทเชิง supervisory/physical และไม่แทนที่หรือลบ KCL row

ก้าวเวลาปกติใช้ implicit trapezoidal แบบ coupled
\begin{equation}
x_{k+1}-x_k-\frac{h}{2}[f(x_k,y_k)+f(x_{k+1},y_{k+1})]=0,qquad
g(x_{k+1},y_{k+1})=0.
\end{equation}
ก้าวแรกหลัง discontinuity ใช้ backward-Euler ครึ่งก้าวสองครั้ง
\begin{equation}
x_{m+1}-x_m-\frac{h}{2}f(x_{m+1},y_{m+1})=0
\end{equation}
ก่อนกลับสู่ trapezoidal วิธี Rannacher restart นี้ลด ringing เชิงตัวเลขของ trapezoidal ในระบบ stiff
โดยไม่ smooth, clip หรือเปลี่ยน trajectory เชิงฟิสิกส์

เมื่อ logical step หนึ่งต้องแบ่งแบบ dyadic solver จะจำระดับ accepted subdivision ล่าสุดเพื่อใช้เป็น
จุดเริ่มของ logical step ถัดไป แล้วค่อยลดระดับเมื่อก้าวหยาบกลับมาผ่านได้ ทุก leaf ยังแก้ implicit residual
เดิมด้วย Newton tolerance เดิม กลไกนี้ไม่เปลี่ยนสมการ ไม่เปลี่ยน event และไม่ลด acceptance gate
ประโยชน์คือไม่ต้องลอง coarse ancestor ที่เพิ่งพิสูจน์แล้วว่าไม่ผ่านซ้ำทุก $0.1$~s ในช่วง fault และ handback

severity รายอุปกรณ์ที่ใช้ตัดสินการคืนโหมดมีเฉพาะพจน์แรงดันและความถี่ตามที่กำหนด
\begin{equation}
J_{V,i}=\frac{\bigl||V_i|-|V_{i,healthy}|\bigr|}{0.10},\qquad
J_f=\frac{|f_{COI}-60|}{0.50},\qquad
S_i=\operatorname{sat}_{[0,1]}\!\left(0.5J_{V,i}+0.5J_f\right).
\end{equation}
$|V_{i,healthy}|$ คือค่า power flow ตอน SG online ที่บัสของ IBR ตัวนั้น ไม่ใช้ค่า 1 pu เหมารวมทุกบัส
RoCoF, active-power error, SCR, PLL-lock และ reference availability ไม่ถูกเฉลี่ยเข้า $S_i$;
hard admissibility check ที่เกี่ยวข้องยังตรวจแยกและไม่สามารถถูก severity ที่ต่ำกว่าหักล้างได้

ขณะ SG offline ระบบใช้ $S_i$ สองพจน์เดิมแบบ real time ทั้งขาเพิ่มและขาลด support ถ้า severity ระบบ
สูงถึง $\Gamma_{on}=0.65$ ต่อเนื่อง $T_{d,on}=0.10$~s ตัวเลือกจะหา authenticated feasible strict
superset ที่เล็กที่สุดของชุด GFM ปัจจุบันและ commit ผ่าน transaction ถ้า severity ต่ำกว่า
$\Gamma_{off}=0.35$ ต่อเนื่อง $T_{d,off}=1.00$~s จึงพิจารณา feasible subset ได้ แต่ตราบใดที่ SG ยัง
offline ต้องเหลือ GFM อย่างน้อยหนึ่งตัวและต้องมี authenticated reference owner ของ island เสมอ
ในผลจริง SG trip ที่ 20~s เริ่มด้วย GFM หนึ่งตัว แล้วความเครียดที่วัดได้ทำให้เพิ่มอีกสามตัวที่ 21.2~s
ดังนั้นการเปลี่ยน 1 เป็น 4 GFM เป็นผลของ supervisor ไม่ใช่ตารางเวลาที่บังคับจำนวนไว้ล่วงหน้า

\subsection{SG synchronizer และเหตุผลที่ reclose เดิมไม่ผ่าน}

เมื่อ breaker ของ SG เปิดอยู่ $T_e=0$ แต่ rotor และ prime mover ยังมีพลวัต
\begin{align}
2H\dot\omega_{SG}&=P_m-D\omega_{SG}, & \dot\delta_{SG}&=\omega_0\omega_{SG}.
\end{align}
engine เดิมเปรียบเทียบ $\omega_{SG}$ กับศูนย์ deviation หรือ 60~Hz แม้ grid ที่ GFM สร้างมีความถี่อื่น
หลัง topology restore ผลก่อนแก้มี grid ประมาณ 62.657~Hz แต่ SG อยู่ใกล้ 60~Hz ทำให้ relative phase
หมุนผ่านกรอบ $\pm10^\circ$ ตลอดและไม่มีทางค้างครบ 0.5~s การ timeout นั้นจึงเกิดจาก reference-frequency
contract ผิด ไม่ใช่ข้อพิสูจน์ว่า SG ทางฟิสิกส์ reclose ไม่ได้

controller ที่แก้แล้ววัด grid สดและกำหนด
\begin{align}
e_\theta&=\operatorname{wrap}(\angle V_{bus}-\angle V_{SG,oc}), &
e_\omega&=\omega_g-\omega_{SG},\\
P_c&=\operatorname{sat}_{[0,P_{max}]}
\left(D\omega_g+K_\omega e_\omega+K_\theta e_\theta\right),\\
K_\omega&=4H\zeta\omega_n-D, &
K_\theta&=\frac{2H\omega_n^2}{\omega_0},\\
T_{sv}\dot P_{sv}&=-P_{sv}+P_c, &
T_{ch}\dot P_m&=-P_m+P_{sv}.
\end{align}
สมการ gain มาจากการวาง pole ของ relative angle/speed pair ที่ได้จาก swing equation ของโครงการเอง
โดยใช้ $\omega_n=0.8$~rad/s, $\zeta=1$, $T_{sv}=0.2$~s และ $T_{ch}=0.4$~s
ส่วน voltage matcher ปรับ field input แยกจาก mechanical synchronizer linearization ที่รวม actuator lag
ทั้งสองให้ eigenvalue ทุกตัวอยู่ซีกซ้ายและ $\max\Re(\lambda)<-0.5$~s$^{-1}$

คำขอ $sg\_on=145$~s เป็นเวลาเริ่มอนุญาต ไม่ใช่คำสั่งปิด breaker ทันที case ให้โอกาส synchronizer
20~s โดยไม่เปลี่ยน threshold หรือ dwell 0.5~s ผลจริงปิดที่ \RunReclose~s และ guard ขณะปิดคือ
\begin{equation}
\Delta V=\RunSyncDV~\text{pu},\qquad
\Delta f=\RunSyncDF~\text{pu},\qquad
\Delta\theta=\RunSyncDTheta^\circ.
\end{equation}
ทุกค่าผ่านกรอบเดิมก่อนทำ atomic right-limit KCL transaction แล้ว reference owner จึงย้ายกลับ SG
โดยที่โหมด IBR ยังไม่เปลี่ยนใน transaction นี้

หลัง SG reclose ไม่มีคำสั่ง hard-code ให้ IBR ทุกตัวกลับ GFL พร้อมกัน SG ต้องผ่าน synchronism dwell ก่อน
จากนั้น GFM แต่ละตัวต้องมี $S_i<\Gamma_{off}$ ต่อเนื่องครบ $T_{d,off}$ และผ่าน transfer/KCL transaction
ของตนเอง ผลจริง release ทีละตัวที่ \RunReleaseOne, \RunReleaseTwo, \RunReleaseThree และ
\RunReleaseFour~s และเป็น all-GFL ตั้งแต่ \RunFinalRelease~s เป็นต้นไป
