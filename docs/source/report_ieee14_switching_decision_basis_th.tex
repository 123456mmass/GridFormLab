\begin{abstract}
\noindent
โครงข่าย IEEE-14 ที่ใช้ศึกษามีเครื่องกำเนิดซิงโครนัสหนึ่งเครื่องที่บัส 1 และ
คอนเวอร์เตอร์สองโหมดสี่ตัวที่บัส 2, 3, 6 และ 8 ซึ่งรันแบบ grid-following (GFL)
หรือ grid-forming (GFM) ได้ เมื่อเครื่องกำเนิดหลุดออกจากระบบ supervisor
ต้องตัดสินใจว่าจะเลื่อนคอนเวอร์เตอร์ขึ้นเป็น GFM กี่ตัวและตัวไหน รายงานนี้พิสูจน์
จากโค้ดที่ส่งมอบและ cache ผลลัพธ์ที่ส่งมอบว่า จำนวนที่เลื่อนขึ้นไม่ได้เลือกจาก
เป้าหมายเสถียรภาพ และไม่ได้ใช้หลัก ``ยิ่งมากยิ่งปลอดภัย'' แต่คือ
\emph{superset เชิงเข้มที่มี cardinality ต่ำที่สุด} ของเซตที่กำลัง form อยู่
ซึ่งปรากฏในตารางความเป็นไปได้ที่ authenticate ไว้ล่วงหน้า และตารางนั้น
\emph{ไม่ monotone} ในจำนวนสมาชิก เซตที่เป็นไปได้ทั้ง 15 แบบมีเพียง 7 แบบที่
ยอมรับได้ และ\emph{ทุก}เซตที่มีสามตัวไม่มี equilibrium เลย (residual ของ
coupled Newton $3.28$--$3.61\times10^{2}$) เกณฑ์การยอมรับคือ damping-ratio floor
ที่ทนทาน $\zmin = 0.05$ ประเมินที่ finite-difference step สามค่าที่ freeze ไว้
และเซตสี่ตัวยอมรับได้แต่มี damping น้อยที่สุดในเจ็ดเซต
($\zworst = 0.1223$ เทียบกับ $0.2549$--$0.2676$) ค่า short-circuit ratio
ที่บัสคอนเวอร์เตอร์อยู่ในช่วง $2.30$--$2.73$ ทุกหน้าต่างเวลาที่เป็นเกาะ
ต่ำกว่า WECC strong-grid floor ที่ 3 บน $98.61\%$ ของ converter-sample ทั้งหมด
และต่ำกว่าทั้ง $100\%$ ของหน้าต่างหลังทริปและหลัง reclose ลำดับเหตุการณ์
adaptive ที่ส่งมอบเลื่อนขึ้นครั้งละหนึ่งตัว ถือสองตัวเป็นส่วนใหญ่ของหน้าต่าง
ที่เป็นเกาะ และไปถึงสี่ตัวเฉพาะเมื่อไม่มีตัวเลือกที่เล็กกว่านั้นยอมรับได้
สุดท้าย รายงานวัด mode ความล้มเหลวของ index สลับโหมดสองเทอม (แรงดัน/ความถี่)
ที่ใช้อยู่ได้ห้าแบบ บน run ที่ส่งมอบ --- หนึ่งในนั้นคือครึ่งความถี่ของ index
\emph{เหมือนกันทั้งสี่คอนเวอร์เตอร์} ตลอด $3679$ sample --- และออกแบบ index
เพิ่มเติมสองตัว --- RoCoF ($df/dt$) และ RoCoV ($d|V|/dt$) --- ซึ่งแต่ละตัว
เข้าเงื่อนไขของตัวเองแทนการถ่วงน้ำหนักรวมเป็นสเกลาร์เดียว
\end{abstract}

\subsection{คำถามทั้งห้า}

\begin{enumerate}[leftmargin=1.9em]
\item \textbf{จำนวนที่เลื่อนขึ้น} ในโค้ดโมเดลล่าสุด ทำไมการสลับไม่ได้ทำให้
      คอนเวอร์เตอร์ทุกตัวเป็น grid-forming แต่เลือกแค่หนึ่งหรือสองตัว
\item \textbf{Damping margin} คำนวณจากปริมาณอะไร คำนวณอย่างไร และทำไมจึงใช้
      ปริมาณนั้น
\item \textbf{ความแข็งของเกาะ} ค่า short-circuit ratio (SCR) ที่บัสคอนเวอร์เตอร์
      เป็นเท่าไรเมื่อเครื่องกำเนิดซิงโครนัสถูกทริปออก
\item \textbf{ทั้งสี่ตัวเป็น GFM} จะเกิดอะไรขึ้น ทำไมจึงไม่ดี และกริดแข็งไม่ดีหรือ
\item \textbf{Index ที่ใช้สลับ} ปัจจุบันใช้แค่แรงดันกับความถี่ ซึ่งเห็นว่าน้อยเกินไป
      และทำให้เกิด false decision ได้ ข้อเสนอคือ index เพิ่มเติมสามตัว
\end{enumerate}

\subsection{คำว่า ``พิสูจน์'' ในรายงานนี้หมายถึงอะไร และไม่หมายถึงอะไร}

รายงานนี้พิสูจน์ข้อความสองชนิดที่ต่างกัน และแยกมันออกจากกันตลอด

\paragraph{ข้อความภายในโมเดล} พิสูจน์ได้โดยอ่านโค้ด production ที่ run ที่ส่งมอบ
รันจริง ``การเลื่อนขึ้นคือ superset เชิงเข้มที่มี cardinality ต่ำที่สุด'' เป็น
ข้อความชนิดนี้ มันเป็นสมบัติของ \code{select\_support\_augmentation\_candidate.m}
และของตารางที่ run นั้นบริโภค จึงเป็นจริงกับทุกรันของโค้ดนี้ ไม่ใช่แค่ run ที่ส่งมอบ

\paragraph{ข้อความเกี่ยวกับวิถีคำตอบ} พิสูจน์โดยการวัดบน artefact ที่ระบุชื่อได้
``SCR ของเกาะเป็น 2.53 เมื่อเครื่องกำเนิดออก'' เป็นข้อความชนิดนี้ จริงสำหรับ
\code{adaptive\_250s.mat} และโครงข่ายกับ dispatch ที่ cache นั้นสร้างขึ้นมา
และไม่ได้อ้างว่าเป็นจริงโดยทั่วไป

ไม่มีข้อความใดในรายงานนี้พิสูจน์ด้วยการให้เหตุผลอย่างเดียว ที่ใดเสนอ

\subsection{ขั้น 1 --- เมื่อไรจึงขอ support}

สำหรับคอนเวอร์เตอร์ที่สลับโหมดได้และออนไลน์ทุกตัว ตัวขับสร้าง

\begin{equation}
\Ssev_i \;=\; \operatorname{sat}\!\left(\tfrac{1}{2}J_{V,i} + \tfrac{1}{2}J_f\right),
\qquad
J_{V,i} = \frac{|V_i - V_{i,\text{healthy}}|}{0.10},
\qquad
J_f = \frac{|f_{\mathrm{COI}} - 60|}{0.50},
\label{eq:severity}
\end{equation}

โดย $\operatorname{sat}(x) = \min(1,\max(0,x))$
\code{(ts\_simulate\_ibr\_hybrid.m:3631)} ฐาน $0.10\pu$ และ $0.50$\,Hz
ตรึงไว้ที่ \code{:1675--1677} และ $V_{i,\text{healthy}}$ คือแรงดัน power flow
ก่อนเหตุการณ์ของบัสคอนเวอร์เตอร์ตัวนั้นเอง เงื่อนไขการเลื่อนขึ้นและปลดลงคือ

\begin{equation}
\text{augment} \;=\; \bigl|\{\,i \in \text{GFL} : \Ssev_i \ge 0.65\,\}\bigr| > 0,
\qquad
\text{release} \;=\; \forall i,\; \Ssev_i < 0.35,
\label{eq:triggers}
\end{equation}

โดยต้องคงอยู่นาน $T_{d,\mathrm{on}} = 0.10$\,s และ $T_{d,\mathrm{off}} = 1.00$\,s
ตามลำดับ \code{(:852--900)} และค่า threshold ตั้งไว้ที่ \code{:1664--1667}
สมบัติสามข้อของ~\eqref{eq:triggers} มีความสำคัญในหัวข้อถัด ๆ ไป

\begin{itemize}
\item เทอม augment เป็น \code{any} เหนือ\emph{ตัวที่ตามอยู่} index จึงถามว่า
      ``มีคอนเวอร์เตอร์ grid-following ตัวใดกำลังเครียดหรือไม่'' ไม่ได้ถามว่า
      ``ระบบเสถียรหรือไม่'' และไม่ได้ถามว่า ``ตัวไหนเป็นต้นเหตุ''
\item เทอม release เป็น \code{all} hysteresis ไม่สมมาตรโดยเจตนา: เพิ่ม support
      เมื่อตัวตามตัวแรกมีปัญหา และถอนออกเมื่อทุกตัวสบายครบหนึ่งวินาทีเต็ม
\item ไม่มีเทอมใดใน~\eqref{eq:severity} เป็นปริมาณเสถียรภาพ ความเป็นไปได้
      small-signal margin เพดานกระแส และความเป็นเจ้าของ reference อยู่ที่อื่น
      ทั้งหมด และหัวข้อ~\ref{sec:indices} จะโต้ว่านี่ถูกต้อง --- แต่
      \emph{ชุด} ปริมาณที่เข้าสู่ขั้น 1 นั้นเล็กเกินไป
\end{itemize}

\subsection{ขั้น 2 --- ตัวไหน}

ขั้น 1 ให้ทิศทาง ไม่เคยให้เซต เซตมาจากตารางคอนฟิกูเรชัน candidate ที่คำนวณ
ก่อน simulation เริ่ม (\code{ibr\_selector\_table}) และกฎขณะรันคือ
\code{select\_support\_augmentation\_candidate}

\begin{proposition}[superset ที่ยอมรับได้และมี cardinality ต่ำที่สุด]
\label{prop:superset}
ให้ $\mathcal{F}$ เป็นเซตที่ form อยู่ ณ ขณะตัดสินใจ และ $\mathcal{T}$ เป็นเซตของ
แถวตารางที่ทั้ง \code{feasible} และ \code{ready\_to\_commit} เป็นจริง
ปลายทางที่คืนกลับคือแถว $c \in \mathcal{T}$ ที่เล็กที่สุดตามลำดับ (i)
$|\mathrm{selected}(c)|$; (ii) $-\mathrm{margin}(c)$; (iii) index tuple ที่เลือก
แบบ lexicographic; (iv) reference index --- ภายใต้เงื่อนไข
$\mathcal{F} \subsetneq \mathrm{selected}(c)$ กล่าวคือปลายทางต้องเป็น superset
\emph{เชิงเข้ม} ของเซตปัจจุบัน
\code{(select\_support\_augmentation\_candidate.m:54--58, 101--112)}
ถ้าไม่มีแถวเช่นนั้น ฟังก์ชันคืน \code{found=false} และ supervisor คงเซตเดิมไว้
มันไม่สร้าง candidate ขึ้นเองและไม่ผ่อน gate ใด ๆ
\end{proposition}

ผลที่ตามมาสองข้อทันที และเป็นคำตอบตรงของข้อ 1

\begin{enumerate}[leftmargin=1.9em]
\item \textbf{เป้าประสงค์ cardinality เป็นการหาค่าน้อยสุด ไม่ใช่มากสุด}
      ไม่มีสิ่งใดในข้อเสนอ~\ref{prop:superset} ให้รางวัลกับการเพิ่มคอนเวอร์เตอร์
      ปลายทางสามตัวจะถูกเลือกเหนือสองตัวก็ต่อเมื่อไม่มี superset สองตัวใด
      ที่ยอมรับได้
\item \textbf{การเลือกไม่ใช่การเลือกใหม่โดยอิสระ} เพราะปลายทางต้องมีเซตปัจจุบันอยู่ด้วย
      supervisor จึงตอบว่า ``เกาะต้องใช้สี่ตัว'' ด้วยการเลื่อนสี่ตัวพร้อมกันจาก
      ตัวเดียวไม่ได้ มันเพิ่มได้เฉพาะจากที่มีอยู่ และเพิ่มน้อยที่สุดเท่าที่ตารางอนุญาต
\end{enumerate}

\subsection{ขั้น 3 --- เปลี่ยนอย่างไร}

      ด้วยเหตุเชิงกลไก: ไม่มีคอนเวอร์เตอร์ที่เหลืออยู่ฝั่ง grid-following
      ตัวใดตัวหนึ่งถูกละเมิดขีดจำกัดการทำงาน ($\{2,3\}$, $\{2,5\}$, $\{3,5\}$,
      $\{4,5\}$) หรือสมดุลกำลังสี่ทางไม่มีคำตอบ (สี่เซตที่มีสามตัว)
      ทั้งสองตระกูลรายงานความล้มเหลวด้วยชื่อ ไม่ใช่ด้วย margin ต่ำ
\item \textbf{เซตสี่ตัวยอมรับได้แต่เป็นตัว outlier} damping ratio ที่แย่ที่สุด
      $0.1223$ น้อยกว่าครึ่งของทุกเซตที่ยอมรับได้อื่น หัวข้อ~\ref{sec:damping}
      แสดงว่าตัวเลขนั้นมาจากไหนและทำไมจึงเป็นสิ่งที่ถูกต้องที่จะ gate
\end{enumerate}

\begin{remark}[ทำไมใช้ตารางที่คำนวณล่วงหน้า ไม่ค้นหาขณะรัน]
candidate จะถูกยอมรับก็ต่อเมื่อแก้ equilibrium ของตัวเองแล้วและประกอบสเปกตรัม
full-KCL ของตัวเองที่ขนาด perturbation สามค่าครบ กระบวนการนั้นใช้เวลาหลายวินาที
ต่อ candidate และวางไว้ใน time step ที่ยอมรับแล้วไม่ได้ การคำนวณจักรวาลทั้งหมด
ล่วงหน้ายังทำให้การตัดสินใจขณะรันเป็นการค้นหลักฐานล้วน ๆ ที่ run ไม่อาจมีอิทธิพลได้
ซึ่งเป็นสิ่งที่ทำให้ข้อเสนอ~\ref{prop:superset} กล่าวถึงโค้ดได้ ไม่ใช่กล่าวถึง
วิถีคำตอบใดวิถีคำตอบหนึ่ง
\end{remark}

\subsection{การคำนวณ ทีละขั้น}

สำหรับแต่ละเซต candidate ตัวประเมิน
(\code{+stability/ibr\_candidate\_evaluate.m}) รันลำดับต่อไปนี้ ไม่มีขั้นใดถูกข้าม
และการล้มเหลวที่ขั้นใดก็หยุดการประเมินพร้อม identifier ที่ระบุชื่อได้

\begin{enumerate}[leftmargin=1.9em]
\item \textbf{Freeze เกณฑ์} $\zmin$ อ่านจาก contract ของเคสเอง
      \code{case\_data.selector.zeta\_min\_damping} ไม่ใช่จากผู้เรียก และถูก
      ตรวจว่าอยู่ใน $(0,1)$ \code{(:83--93)} สำหรับเคสนี้ $\zmin = 0.05$
\item \textbf{แก้ equilibrium ของปลายทาง} การกำหนดโหมดที่แน่นอนของ candidate
      ถูกสร้างเข้าสู่ชุดอุปกรณ์และสถานะ hybrid แล้วแก้ด้วย coupled Newton
      ที่ tolerance $10^{-8}$ และ 300 รอบ \code{(:314, :326)} เบรกเกอร์เครื่องกำเนิด
      ถูกถือว่าเปิดตลอด เพราะ selector เป็นเจ้าของสัญญาคอนฟิกูเรชันหลังทริป
      และการประเมิน candidate ที่เครื่องกำเนิดต่ออยู่จะ certify ระบบทางกายภาพ
      คนละระบบ \code{(:220--228)}
\item \textbf{บังคับสมการโครงข่าย} KCL residual แบบทุกแถวจริงต้องมี
      $\lVert \cdot\rVert \le 10^{-6}$ \code{(:340--345)} residual ที่วัดได้ของแถว
      ที่ยอมรับได้อยู่ระหว่าง $3.6\times10^{-15}$ ถึง $1.4\times10^{-14}$ \measured
\item \textbf{ประกอบ decision spectrum} โมเดล state-space แบบ full-KCL ประกอบ
      ที่ equilibrium ที่ยอมรับแล้ว ด้วย input $u_{eq}$ ที่แน่นอน, event context
      และชุด active-state index \code{(:355--395)} พิกัด gauge ของมุมโครงข่าย
      ถูกกำจัดด้วย centre-of-inertia $T$-matrix และไม่มี eigenvalue ใดถูกลบ
      หลังการเรียก eigenvalue \code{(:398--400)}
\item \textbf{Damping ratio ต่อ mode} eigenvalue แต่ละตัวของ decision spectrum
      ทางกายภาพลดรูปเป็น
      \begin{equation}
      \zeta_i = \frac{-\operatorname{Re}\lambda_i}{|\lambda_i|}.
      \label{eq:zeta}
      \end{equation}
      รากจริงลบให้ $\zeta = 1$ จึงไม่มีทางเป็น mode ที่จำกัด ราก\emph{ที่}จุดกำเนิด
      มี ratio ไม่นิยาม จึงแมปเป็น $-\infty$ แทนที่จะข้าม เพื่อให้ mode ที่ marginal
      ตกทุก floor ที่เป็นบวกแทนที่จะผ่านอย่างเงียบ ๆ สเปกตรัมว่างก็คืน $-\infty$
      เช่นกัน เพราะการไม่มีหลักฐานไม่ใช่หลักฐานว่ามี damping \code{(:492--516)}
\item \textbf{แย่ที่สุดเหนือสเปกตรัม ไม่ใช่ตัวขวาสุด} ปริมาณที่รายงานคือค่าต่ำสุด
      ของ~\eqref{eq:zeta} เหนือ decision spectrum ทั้งหมด นี่เป็นการเบี่ยงจาก
      การอ่าน margin จาก $\max\operatorname{Re}\lambda$ โดยเจตนา: mode ที่
      damping แย่ที่สุดโดยทั่วไปไม่ใช่ตัวขวาสุด และการอ่าน ratio จาก eigenvalue
      ตัวขวาสุดจะพลาดมันไป \code{(:402--410)}
\item \textbf{ทำซ้ำที่ขนาด perturbation สามค่า} การประกอบทั้งหมดทำใหม่ที่
      finite-difference step $\varepsilon \in \{1.5,\,3,\,6\}\times10^{-6}$
      (ฐานที่ audit ไว้คูณ $0.5$, $1$, $2$) และทดสอบที่\emph{ทุก}สมาชิก
      \code{(:412--448)}
\item \textbf{gate} candidate ยอมรับได้เมื่อ
      \begin{equation}
      \forall \varepsilon \in \mathcal{E}:\quad
      \max\operatorname{Re}\lambda(\varepsilon) < 0
      \quad\text{และ}\quad
      \min_i \zeta_i(\varepsilon) \;\ge\; \zmin,
      \label{eq:gate}
      \end{equation}
      กล่าวคือทั้งสามขนาด perturbation ต้องตรงกันทั้งเรื่องเสถียรภาพและ
      ratio floor ความไม่ตรงกันล้มเหลวแบบปิด (fail closed) สำหรับตารางที่ส่งมอบ
      ทั้งสามตรงกัน และ $\zworst$ ที่รายงานคือค่าที่แย่ที่สุดในสาม
\end{enumerate}

\subsection{ทำไมใช้ damping \emph{ratio} ไม่ใช่อัตราการสลาย}

โค้ดยังเก็บปริมาณที่สองซึ่งเก่ากว่า: $\greq = 0.1$\,rad/s ซึ่งเป็น reference
decay rate แล้วให้
\begin{equation}
\mathrm{margin} = -\max\operatorname{Re}\lambda - \greq .
\label{eq:margin}
\end{equation}
มันถูกใช้ และใช้เป็น\emph{ordering key} อย่างเดียวในบรรดา candidate ที่ยอมรับได้
\code{(:452--462)} ความแตกต่างนี้ไม่ใช่เรื่องผิวเผิน

rate floor สัมบูรณ์ถามว่า $\operatorname{Re}\lambda \le -\gamma$ จึงผูกกับ
ความถี่โดยผล: $\gamma$ ค่าเดียวกันเป็นข้อเรียกร้องที่ไม่หนักสำหรับ mode เร็ว
และเป็นไปไม่ได้สำหรับ mode ช้า ส่วน ratio floor ขอให้ mode สลายภายใน
$\zeta^{-1}$ ของหนึ่งเรเดียน และไม่แปรตามการเปลี่ยนสเกลเวลา ทั้งสองตระกูล
บรรจบกันที่ความถี่เดียวเท่านั้น

\begin{equation}
f^{*} = \frac{\greq}{2\pi\zmin} = \frac{0.1}{2\pi(0.05)} = 0.3183\ \mathrm{Hz},
\label{eq:fstar}
\end{equation}

ซึ่งเป็นค่าที่สัญญาของเคบบันทึกไว้เป็น \code{equivalence\_frequency\_Hz}
ห่างจาก $f^{*}$ ออกไปทั้งสองตระกูลเป็นข้อเรียกร้องที่ต่างกัน \code{(:402--410)}
plant นี้มี mode ตั้งแต่ราว $0.02$\,Hz --- swing เชิงกลไฟฟ้าของเกาะที่ถูกทำให้ช้า
ด้วยความเฉื่อยน้อยของคอนเวอร์เตอร์ --- ขึ้นไปถึงแถบ current loop ซึ่งกว้างกว่า
สามทศวรรษ ดังนั้นไม่มีอัตราสัมบูรณ์ค่าใดที่เป็น floor ที่มีความหมายตลอดช่วง

\subsection{ทำไมจึงเป็น 0.05}

ค่านี้ถูกประกาศโดยเคส ไม่ได้ถูกรายงานเลือก

\begin{quote}\small
\begin{tabular}{@{}ll@{}}
\code{acceptance\_criterion} & \code{'damping\_ratio\_floor'}\\
\code{derivation} & \code{'5\% damping at the 1\,Hz electromechanical mode:}\\
                 & \code{zeta >= 0.05 for every mode of the physical decision spectrum'}\\
\code{gamma\_req\_role} & \code{'candidate ordering key and reference decay rate; NOT the acceptance gate'}\\
\code{frozen\_before\_candidate\_eval} & \code{1}\\
\end{tabular}
\end{quote}

ที่มาจึงมีสามชั้น และควรกล่าวให้ชัด \emph{ตัวเลข} $0.05$ คือเกณฑ์ damping
เชิงกลไฟฟ้าแบบฉบับ ใช้ที่นี่เป็น acceptance floor ระดับเคสไม่ใช่เป็นเป้า
ของ simulation \emph{ขอบเขต} --- ``ทุก mode ของ physical decision spectrum
ที่ทุกขนาด perturbation'' --- เป็นการเสริมความของโปรเจกต์เอง: กลุ่ม mode
ที่มีสมาชิกหนึ่งตัวแทบไม่มี damping ไม่ได้รับการช่วยเหลือจากการที่ตัวอื่นสบาย
และ margin ที่มีที่ finite-difference step หนึ่งแต่ไม่มีที่ step ถัดไป
ก็ไม่ใช่ margin \emph{ธง frozen} ทำให้เกณฑ์เป็นสมบัติของไฟล์เคส ตรึงก่อน
candidate ใดถูกประเมิน จึงปรับใหม่ให้เข้ากับผลลัพธ์ไม่ได้ นี่คือกลไกที่ทำให้
candidate ยอมรับได้ทั้งที่ $\mathrm{margin} < 0$: $\mathrm{margin}$ เป็น
คะแนนจัดอันดับเทียบ reference rate ส่วน gate คือ ratio

\begin{remark}[gate ไม่ใช่อะไร]
ความเป็นไปได้เป็นสมบัติของ\emph{equilibrium} ที่ establish ด้วยการ linearise
รอบมัน ไม่ได้กล่าวถึงว่าวิถีคำตอบที่มาถึง equilibrium นั้นอยู่ใน
region of attraction ของมันหรือไม่ หัวข้อ~\ref{sec:allfour} แสดงกรณีที่วัดได้
ซึ่ง equilibrium ยอมรับได้แต่การมาถึงไม่
\end{remark}

\subsection{margin ที่วัดได้}

ตาราง~\ref{tab:adm} ให้ทั้งเจ็ดเซต มีสามข้อสังเกตที่ควรกล่าวชัด

\begin{enumerate}[leftmargin=1.9em]
\item \textbf{ทุกเซตที่ยอมรับได้ผ่าน floor อย่างสบาย} $\zworst$ ที่ต่ำที่สุดคือ
      $0.1223$ ซึ่งเป็น $2.45\times$ ของ floor $0.05$ ข้อจำกัดที่ผูกจริงในเคสนี้
      จึงไม่ใช่~\eqref{eq:gate} เลย แต่คือการมีอยู่ของ equilibrium ซึ่งตัด
      $8$ จาก $15$ เซต
\item \textbf{damping ratio กับ decay rate ไม่ตรงกัน และ gate ใช้ ratio}
      บน $\omega$ ลำดับคือ $\{3,4\} > \{2,4\} > \{2,3,4,5\} > \{2\} > \cdots$
      เซตสี่ตัวจึงเป็นเซตที่สลายเร็วเป็น\emph{อันดับสอง} บน $\zworst$ มันแย่ที่สุด
      ด้วยปัจจัยสอง gate ทำตาม $\zworst$
\item \textbf{เซตสองตัวเป็นจุดที่ดีที่สุดเชิง small-signal และ $\{3,4\}$ ดีที่สุด
      ในนั้น} $\{3,4\}$ มีทั้ง $\omega$ ติดลบมากที่สุด ($-0.568138$) และ ratio
      ระดับหัวแถว ($0.2560$) นี่คือเหตุผลที่การศึกษาแบบ pinned arm ใช้ $\{3,4\}$
      เป็นคู่แข่งคอนฟิกูเรชันตรึงกับนโยบาย adaptive
\end{enumerate}

\section{ความแข็งของเกาะ (SCR) หลังเครื่องกำเนิดถูกทริป}\label{sec:scr}
%=============================================================================

\subsection{โปรเจกต์นิยาม SCR อย่างไร}

\code{+stability/ibr\_scr\_metrics.m} นิยามต่อคอนเวอร์เตอร์ที่ออนไลน์แต่ละตัว

\begin{equation}
\mathrm{SCR}_i = \frac{S_{sc,i}}{S_{\mathrm{rated},i}},
\qquad
S_{sc,i} = \frac{|V_i|^2}{|Z_{th,ii}|}\,S_{\text{base}},
\qquad
Z_{th,ii} = \left[\,\mathbf{Y}^{-1}\mathbf{e}_i\,\right]_i ,
\label{eq:scr}
\end{equation}

โดย $\mathbf{Y}$ สร้างจากข้อมูลสาย --- รวม tap และ phase shift และ bus shunt
แต่\emph{ไม่}รวม admittance ของโหลด เพื่อให้ผลวัดความแข็งของโครงข่าย
ไม่ใช่การโหลด --- และ bus อ้างอิงถูกถือว่า grounded เพื่อให้ Thevenin equivalent
คิดโดยลัดวงจรแหล่งแรงดัน rating คือ MVA base ของคอนเวอร์เตอร์เอง ถ้าขาดไป
การประเมินล้มเหลวแบบปิดแทนที่จะอนุมาน rating ขึ้นมา threshold คือ
$\mathrm{SCR} > 3$ จากสัญญา WECC REGC\_A strong-grid และการเปรียบเทียบเป็น
เชิงเข้ม: $\mathrm{SCR} \le 3$ คือการปฏิเสธ

\subsection{gate นี้ใช้กับตระกูลโมเดลนี้ไม่ได้}

ต้องกล่าวก่อนตัวเลขใด ๆ เพราะเข้าใจผิดได้ง่ายว่า diagnostic ที่ประกาศอยู่
คือ gate ที่ทำงาน ใน \code{ibr\_scr\_metrics.m:266--276} screening profile
ถูกบังคับสำหรับตระกูล dual แบบ full-state ของโปรเจกต์

\begin{quote}\small
\code{scr\_profile = 'not\_applicable\_full\_state\_source\_model'}\quad สำหรับ
\code{model\_id} $\in$ \{\code{eecon49\_dual}, \code{decoupled\_dual}\}
\end{quote}

ผลที่ตามมาคือ \code{eligible\_for\_scr = false} และ \code{pass = true}
พร้อมเหตุผลที่บันทึกไว้

\begin{quote}\itshape
``SCR threshold not applicable to this full-state model; equilibrium, limits and
full-KCL SSSA remain mandatory''
\end{quote}

\measured{} --- ตรวจแล้วกับคอนเวอร์เตอร์ทั้งสี่ตัวในเคสที่ส่งมอบ ทุก entry ใน
\code{per\_resource} รายงาน \code{eligible\_for\_scr = 0}, \code{SCR = NaN},
\code{pass = 1} เหตุผลสมเหตุสมผล: screening ของ REGC\_A มีไว้สำหรับโมเดล plant
แบบ current-source แบบย่อ ส่วน \code{eecon49\_dual} แบก AC filter, DC link,
PLL/VSG และ loop ควบคุมทั้งสองไว้เป็น state ชัดแจ้ง ความล้มเหลวบนกริดอ่อน
ที่ screening ป้องกันจึงถูกแทนในโมเดลแล้ว ไม่ได้ถูกสมมติทิ้ง กระนั้นตัวเลข SCR
ก็ยังเป็นข้อความ\emph{ทางกายภาพ} ที่มีความหมายเกี่ยวกับเกาะ และ run ประกาศมัน
เป็น diagnostic ราย sample

      แต่กระแสโหลดยกแรงดันบัส และ $|V|^2$ เป็นตัวเศษ นี่เป็นเครื่องเตือนว่า
      \eqref{eq:scr} ตามที่ implement เป็นปริมาณที่อ้างอิงแรงดัน ไม่ใช่ค่าคงตัว
      ของโครงข่ายล้วน ๆ และควรเปรียบเทียบภายในหน้าต่างเดียวกัน ไม่ใช่ข้ามหน้าต่าง

      ขณะเครื่องกำเนิดต่ออยู่ impedance เดียวกัน ตัวหารต่างกัน ตัวเลขที่ยกมา
      ในตาราง~\ref{tab:scr} คือตัวที่ diagnostic ของ supervisor ที่กำลังรัน
      ผลิตออกมา บน convention rated-MVA
\end{enumerate}

(equilibrium ไม่มีอยู่) นโยบายที่ถามแค่ ``ปลายทางเสถียรหรือไม่'' จะยอมรับ
สี่ตัวและเสียเกาะ นี่คือเหตุผลที่ขั้น 3 ของไปป์ไลน์จำลองซ้ำก่อน commit และ
เหตุผลที่ certificate เป็น forward trial ไม่ใช่การตรวจ eigenvalue ครั้งที่สอง
\end{remark}

\subsection{ทำไมสี่ตัวจึงแย่กว่า --- สามข้อ แต่ละข้อมีขอบเขต}

ข้อความที่ซื่อตรงแคบกว่า ``สี่ตัวแย่'' สามข้อแยกกัน แต่ละข้อมีหลักฐานของตัวเอง

\begin{enumerate}[leftmargin=1.9em]
\item \textbf{มันเป็นคอนฟิกูเรชันที่ยอมรับได้แต่ damping น้อยที่สุด}
      $\zworst = 0.1223$ เทียบกับ $0.2549$--$0.2676$ ของอีกหกเซต ต่างกันราว
      สองเท่า วัดแล้ว และเป็นสมบัติของ equilibrium (ตาราง~\ref{tab:adm})
\item \textbf{การมาถึงของมันไม่ทนทาน} วัดแล้ว และเป็นสมบัติของวิถีคำตอบ

\item \textbf{มันถูกเลือกในฐานะส่วนที่เหลือ ไม่ใช่การตัดสิน} ที่ $t = 53.3795$\,s
      เซตสี่ตัวเป็นปลายทางที่ยอมรับได้\emph{เพียง}แบบเดียว
      (ตาราง~\ref{tab:resolution}) นโยบายไม่ได้ชอบสี่เหนือสอง มันไม่มีทางเลือกอื่น
\end{enumerate}

เทียบกับสามข้อนั้น มีข้อความที่วัดได้หนึ่งข้อชี้ไปทางตรงข้าม และควรอยู่ใน
รายการเดียวกัน เพราะรายงานที่ละมันไว้ไม่ใช่การพิสูจน์

\begin{quote}
ในการทดลองเรื่องความรุนแรงของโหลดในบันทึก defect คอนฟิกูเรชันสี่ตัว
รับ load deficit $2.0\pu$ ได้ ขณะที่คอนฟิกูเรชันสองตัวรับไม่ได้ ---
สองตัว slips ที่ deficit เดียวกัน \measured
\end{quote}

ข้อสรุปที่ป้องกันได้จึงไม่ใช่ ``forming น้อยกว่าดีกว่า'' แต่คือ

\begin{quote}\itshape
จำนวนคอนเวอร์เตอร์ที่ form ไม่ใช่พารามิเตอร์อิสระ และเสถียรภาพไม่ monotone
ตามมัน ปลายทั้งสองข้างผิด: เมื่อไม่มี former เลยเกาะตายใน $20$\,s และเมื่อตรึง
สี่ตัวเกาะตายใน $25.5$\,s จำนวนต้องถูกเลือกต่อคอนฟิกูเรชัน จาก margin ที่
certified และจากการมาถึง และการจัดอันดับต้องได้รับอนุญาตให้ชอบสองเหนือสี่
เมื่อสองถูก certify
\end{quote}

\subsection{กริดแข็งไม่ดีหรือ}\label{sec:stronggrid}

ดี และเกาะนี้ไม่มี --- ซึ่งเป็นข้อโต้แย้ง\emph{สนับสนุน} grid-forming
ไม่ใช่ต่อต้าน ความยากคือ ``กริดแข็ง'' กับ ``คอนเวอร์เตอร์ grid-forming มากขึ้น''
เป็นสองปริมาณที่ต่างกัน และมีสี่ข้อที่กั้นมันไว้

\begin{enumerate}[leftmargin=1.9em]
\item \textbf{ในตัวชี้วัดของโปรเจกต์นี้ จำนวน forming ไม่เข้าไปใน ratio เลย}
      $\mathbf{Y}$ ใน~\eqref{eq:scr} สร้างจากข้อมูลสาย, bus shunt และ
      การ ground บัสอ้างอิง และจากอย่างอื่นไม่ได้ SCR ที่ประกาศจึงไม่แปรตาม
      จำนวนคอนเวอร์เตอร์ที่ form การเลื่อนคอนเวอร์เตอร์ขึ้นจึงยก SCR ของ
      โครงข่ายที่มันอยู่ไม่ได้ ไม่ว่ามันจะทำอะไรได้อย่างอื่น
\item \textbf{เกาะที่วัดได้อ่อนในทุก sample ที่มีความหมาย} $98.61\%$ ของ
      converter-sample อยู่ที่หรือต่ำกว่า floor 3 ของ WECC และค่าเฉลี่ยหลังทริป
      เป็น $2.30$ premise ข้างหลังคำถามถูกต้อง: นี่คือกริดอ่อน นั่นคือเหตุผล
      ที่เกาะต้องการแหล่งก่อรูปแรงดัน --- และเหตุผลที่คำถามที่น่าสนใจคือกี่ตัว
      ไม่ใช่หรือไม่
\item \textbf{เหนือจำนวนที่ไม่มีตัวตามเหลืออยู่ เกณฑ์ก็หมดประธาน}
      REGC\_A screen plant แบบ grid-following เพราะ PLL ต้องมีบัสที่แข็ง
      เพื่อล็อก เมื่อทั้งสี่ตัว form ไม่มี PLL เหลือให้ป้องกัน และคำถามของ
      screening ก็ว่างเปล่า ปัญหาเปลี่ยนชนิด: ไม่ใช่ ``ตัวตามล็อกได้ไหม''
      อีกต่อไป แต่เป็น ``ตัวควบคุมแหล่งแรงดันสี่ตัวแบ่งกระแสร่วมกันบนโครงข่าย
      ที่ไม่มีตัวใดเปลี่ยน impedance ของมันได้หรือไม่'' หัวข้อ~\ref{sec:admissibility}
      แสดงว่านั่นคือคำถามที่โครงข่ายนี้ตอบได้แย่พอดี --- การแบ่งกันแบบสามตัว
      ทั้งสี่แบบไม่มี equilibrium และการแบ่งกันแบบสี่ตัวมี margin บางที่สุด
\item \textbf{ความแข็งในที่นี้ได้มาจากความเป็นเจ้าของ ไม่ใช่จากการนับจำนวน}
      former หนึ่งตัวที่ voltage loop ของมันเป็นเจ้าของบัสของมัน ให้บัสนั้น
      แรงดันที่นิยามไว้ สิ่งที่อีกสามตัวต้องการไม่ใช่เจ้าของอีกคน แต่เป็น
      แรงดันที่นิยามไว้ที่บัสของตัวเอง โดยเซตที่โครงข่ายแก้ได้จริง
\end{enumerate}

\begin{remark}[สัญชาตญาณถูก แต่ข้อสรุปที่ดึงจากมันไม่ถูก]
``กริดอ่อน $\Rightarrow$ form มากขึ้น'' ฟังดูสมเหตุสมผลในขั้นแรก แต่ล้มที่ขั้นสอง
เพราะจำนวนไม่ใช่ความแข็ง ขอบล่างวัดได้และแข็ง: arm \code{locked\_gfl}
ที่คอนเวอร์เตอร์ทั้งสี่เป็นตัวตาม ตายที่ $t = 20.0000$\,s ---
ขณะทริปนั้นเอง --- ด้วย \code{noVoltageFormingSource} หลัง 43 sample
ต้องมีอะไรสักอย่าง form ขอบบนก็วัดได้เช่นกัน และมันไม่ใช่สี่
\end{remark}

\section{จุดที่ index สองเทอมปัจจุบันล้มเหลว}\label{sec:indices}

ขั้น 1 ของไปป์ไลน์บริโภคปริมาณเพียงสองตัว คือ~\eqref{eq:severity}:
ความคลาดเคลื่อนแรงดันบัส และความคลาดเคลื่อนความถี่ centre-of-inertia
ข้อตัดสินว่าแคบเกินไปนั้นถูกต้อง และ run ที่ส่งมอบวัดได้ห้าวิธีที่มันแคบ
ทั้งห้าวัดกับ \code{adaptive\_250s.mat} สามข้อแรกเป็นสมบัติเชิงโครงสร้างของ
\eqref{eq:severity} และเป็นจริงกับทุกรันของโค้ดนี้

\subsection{เทอมความถี่ไม่แบก identity ของอุปกรณ์}

\begin{equation}
\max_t \Bigl[\max_i J_{f}(t) - \min_i J_{f}(t)\Bigr] \;=\; 0.000\times10^{0}
\qquad\text{ตลอด } 3679 \text{ sample}.
\label{eq:commonmode}
\end{equation}

$J_f$ สร้างจาก $f_{\mathrm{COI}}$ ซึ่งโดยการสร้างเป็นสเกลาร์ระดับโครงข่ายตัวเดียว
คอนเวอร์เตอร์ทุกตัวอ่านค่าเดียวกันในทุกขณะ ครึ่งหนึ่งของ $\Ssev_i$ ใน
\eqref{eq:severity} จึงเป็นเทอม common-mode ที่แยกคอนเวอร์เตอร์ตัวหนึ่งจากอีกตัว
ไม่ได้ ผลที่ตามมาเป็นรูปธรรม: index ตอบได้ว่า ``เกาะถูกรบกวนหรือไม่''
แต่โดยโครงสร้างตอบไม่ได้ว่า ``\emph{ตัวไหน} มีปัญหา'' --- และนั่นคือคำถามที่สอง
ที่ supervisor ต้องตอบ ขั้น 2 ปิดช่องว่างด้วยการจัดอันดับเชิงสถิตที่คำนวณล่วงหน้า
ซึ่งสมเหตุสมผลแต่ตาบอดต่อการรบกวนที่เกิดขึ้นจริง \measured

\subsection{มันอิ่มตัวก่อนจะให้ข้อมูล}

$\Ssev$ ถูก clip ที่ $1$ และไปถึง clip เมื่อ $J_V + J_f \ge 2$ โดยฐานทั้งสอง
ตรึงที่ $0.10\pu$ และ $0.50$\,Hz นั่นคือความคลาดเคลื่อนแรงดันบัสราว $0.2\pu$
ที่ความถี่ nominal ค่าสูงสุดที่วัดได้ตลอด run ที่ส่งมอบคือ
$J_V^{\max} = 7.671$ และ $J_f^{\max} = 2.322$: index ถูกดันไปที่เพดานด้วย
ความคลาดเคลื่อนแรงดันที่เกือบสี่เท่าของ threshold การอิ่มตัว ระหว่าง fault
บัส 9 ($t = 85.0000$--$85.1500$\,s) คอนเวอร์เตอร์ทั้งสี่อยู่ที่ $\Ssev = 1.0000$
นาน $0.147$--$0.151$\,s --- เพียงประมาณ $1.5$ เท่าของ dwell $0.10$\,s
ช่วงการเบี่ยงตลอด run คือ $|V| \in [0.0369,\,1.5232]\pu$ และ
$f_{\mathrm{COI}} \in [58.8391,\,61.1385]$\,Hz

ผลที่ตามมาสองข้อ ข้อแรก ในย่านที่การตัดสินใจเกิดขึ้นจริง index เสื่อมจาก
การวัดแบบมีระดับเป็นธงบอกการรบกวนแบบทวิภาค ข้อสอง fault ที่ยาว
$1.5\times$ ของ dwell คือ transaction ที่รอจะเกิดขึ้น และใน run ที่ส่งมอบ
เหตุผลเดียวที่มันไม่เกิดคือเกาะอยู่ในเซตสูงสุดอยู่แล้ว ---
ซึ่งเป็นการป้องกันโดยบังเอิญ ไม่ใช่โดยการออกแบบ บนเกาะที่เล็กกว่า
fault เดียวกันจะเลื่อนคอนเวอร์เตอร์ขึ้นตอบสนองต่อ transient ที่คำตอบที่ถูก
คือการ ride through \measured

\subsection{มันมองไม่เห็นสถานะอุปกรณ์ และความล้มเหลวของการเป็นสี่ตัวอยู่ที่นั่น}

\subsection{ข้อจำกัดการออกแบบที่กำหนดทั้งสองตัว}

โมดูล reference ที่มีอยู่คำนวณ sub-index ไว้แล้วหกตัว คือ $J_V$, $J_f$, $J_R$
(ซึ่งเป็นอัตราการเปลี่ยนความถี่ของมัน), $J_P$, $J_{\text{SCR}}$,
$J_{\text{lock}}$ \code{(agsi\_reference\_terms.m:113)} และสัญญาการตัดสินใจของ
มันเองระบุว่า \emph{switching consumes $J_V$ and $J_f$ only; every other term
published here is reference-only and enters no gate} \code{(:52--53)}
index สองตัวที่เสนอข้างล่างเป็น\emph{อัตรา}ทั้งคู่: อัตราการเปลี่ยนความถี่
(RoCoF) และอัตราการเปลี่ยนแรงดัน (RoCoV) ไม่มีตัวใดถูกบวกเข้าไปในผลรวมของ

\subsection{Index A --- RoCoF: อัตราการเปลี่ยนความถี่ต่ออุปกรณ์}

\paragraph{นิยาม} สำหรับคอนเวอร์เตอร์แต่ละตัว $\mathrm{RoCoF}_i = df_i/dt$
จากสถานะความเร็วของคอนเวอร์เตอร์ตัวนั้นเอง ปริมาณนี้มีอยู่แล้วในโมดูล reference:
\code{agsi\_reference\_terms.m:153} คำนวณมันต่ออุปกรณ์เป็น \code{dfdev(k)}
แล้ว \code{:165} \emph{ทิ้ง} ค่าต่ออุปกรณ์นั้นโดยยุบทุกอุปกรณ์เป็นสเกลาร์
centre-of-inertia แบบถ่วงน้ำหนักความเฉื่อยที่ประกาศเป็น $J_R$ ข้อเสนอจึงไม่ใช่
การวัดใหม่ แต่คือการเลิกทิ้งค่าต่ออุปกรณ์

\paragraph{ฐาน} $1$\,Hz/s ซึ่งเป็น \code{agsi\_rocof\_base\_Hz\_s} ที่โปรเจกต์
ประกาศไว้ ฐานนั้นถูกจำแนกเป็น \code{ASSUMED\_DIAGNOSTIC} และผู้เรียกแทนค่าได้
และโมดูล reference ระบุไว้เองในฟิลด์ \code{base\_classification} การสร้างแบบที่
ใช้กับฐานอื่นในรายงานนี้จะให้
$\text{df\_base}/T_{d,\mathrm{on}} = 0.50/0.10 = 5$\,Hz/s ฐานที่ประกาศจึงไว
กว่าอีกแบบ ช่องว่างที่มาของค่านี้ถูกระบุไว้ ไม่ได้ถูกซ่อน \proposed

\paragraph{ขอบเขต และทำไมไม่ใช่ตัวกระตุ้น augment} ความถี่ต่ออุปกรณ์ถูกบันทึก
เป็น NaN บน $100.0\%$ ของ sample ที่เป็น grid-following และบน $0.0\%$ ของ sample
ที่เป็น grid-forming \measured{} --- สถานะความเร็วของคอนเวอร์เตอร์มีอยู่พอดีและ
เฉพาะขณะที่เครื่องกำลัง form เพราะกิ่ง grid-following ในโมเดลนี้ไม่แบก swing state
index จึงนิยามบน\emph{เซตที่ form อยู่} เท่านั้น มันขอเลื่อนขึ้นไม่ได้
และไม่ได้ถูกเสนอให้ทำ

\paragraph{หลักฐานที่วัดได้} สามผล บน run ที่ส่งมอบทั้งหมด

\begin{enumerate}[leftmargin=1.9em]
\item \textbf{มันบอกชื่อคอนเวอร์เตอร์ที่รับแรงกระแทกจากการเปลี่ยนโหมด}
      ที่ฐาน $1$\,Hz/s กับ on-dwell ของโปรเจกต์ มี excursion ที่ผ่านเกณฑ์แปดครั้ง
      ใน run และ\emph{เจ็ดในแปดเริ่มภายใน $2$\,ms ของ transaction ที่ supervisor ทำ}
      ที่การเลื่อนขึ้นทั้งสามครั้ง ตัวที่ยิงคือตัวที่เพิ่งถูกเลื่อนขึ้น:
      IBR6 ที่ $t = 22.0888$\,s (เลื่อนขึ้นที่ $22.0887$\,s),
      IBR6 ที่ $t = 51.3404$\,s (เลื่อนขึ้นที่ $51.3403$\,s),
      IBR3 กับ IBR8 ที่ $t = 53.3797$\,s (เลื่อนขึ้นที่ $53.3795$\,s),
      IBR6 ที่ $t = 148.2812$\,s (เลื่อนขึ้นที่ $148.2811$\,s) ครั้งที่แปดคือ IBR2
      ซึ่งเป็น former ที่เหลือตัวเดียว ตอน release ที่ $146.2782$\,s \measured
\item \textbf{สเกลาร์ที่ประกาศอยู่แทนมันไม่ได้} ในแปดหน้าต่างเดียวกัน ค่าสูงสุด
      ต่ออุปกรณ์อยู่ในช่วง $0.13\times$ ถึง $2.01\times$ ของค่าสูงสุด
      centre-of-inertia --- ไม่มีตัวใดเป็นขอบเขตของอีกตัว ความล้มเหลวรุนแรงที่สุด
      พอดีที่การเลื่อนขึ้น: ที่ $t = 53.3795$\,s ค่า $J_R$ ที่ประกาศสูงสุดที่
      $123.04$\,Hz/s ขณะที่สองตัวที่\emph{เข้าใหม่}ไปถึงเพียง $26.16$ และ
      $15.95$\,Hz/s เพราะการถ่วงน้ำหนักความเฉื่อยถูกครอบโดยตัวที่ครองอยู่ซึ่ง
      \emph{ไม่ได้}เปลี่ยนโหมด สเกลาร์รายงานแรงกระแทกของตัวครอง
      และเงียบเรื่องตัวเข้าใหม่ \measured
\item \textbf{ตอน fault เคลียร์ มันแยก former ออกจากกัน} ที่ $t = 85.1500$\,s
      คอนเวอร์เตอร์ที่ form ทั้งสี่ไปถึง $-1050.98$, $-1016.92$, $-1106.62$
      และ $-1212.91$\,Hz/s --- spread $196.0$\,Hz/s หรือ $17.9\%$ ของขนาดเฉลี่ย
      และบอกชื่อ IBR8 ว่าได้รับกระแทกมากที่สุด ขณะที่ $J_R$ ที่ประกาศมี spread
      เท่ากับ $0.000\times10^{0}$ ระหว่างคอนเวอร์เตอร์ทั้ง $3679$ sample \measured
\end{enumerate}

\paragraph{กฎที่เสนอ} RoCoF ไม่สร้าง trigger มันเข้าเป็น\emph{ตัวกันการ release}
และเป็นตัวระบุของ transaction
\begin{equation}
\text{ห้าม release ถ้า } \exists i \in \mathrm{GFM}:\;
\mathrm{RoCoF}_i \ge 1\ \mathrm{Hz/s},
\qquad
\text{และบันทึก } \operatorname*{arg\,max}_i |\mathrm{RoCoF}_i|
\text{ ต่อ transaction}.
\label{eq:ruleA}
\end{equation}
ทิศทางปลอดภัยโดยโครงสร้าง: index มีอยู่เฉพาะบนคอนเวอร์เตอร์ที่ form จึงไม่มีทาง
ขอเลื่อนขึ้น และการกัน release คือทิศทางที่อนุรักษ์นิยม

\paragraph{เส้นทางตรวจสอบ} เล่นลำดับเหตุการณ์ซ้ำ แล้วยืนยันว่า (ก)
\eqref{eq:ruleA} ไม่กัน release ใดที่โยบาย adaptive ทำจริง --- วัดแล้ว
ทั้งสามครั้งเกิดที่ $|\mathrm{RoCoF}| \le 0.066$\,Hz/s จึงไม่มีครั้งใดถูกกัน ---
และ (ข) การระบุที่บันทึกไว้บอกชื่อตัวที่ถูกเลื่อนขึ้นในการเลื่อนขึ้นทั้งสามครั้ง

\subsection{Index B --- RoCoV: อัตราการเปลี่ยนขนาดแรงดันที่บัสคอนเวอร์เตอร์}

\paragraph{นิยาม} $\mathrm{RoCoV}_i = d|V_i|/dt$ ที่บัสของคอนเวอร์เตอร์เอง

\paragraph{ฐาน ที่มาจากการสร้างไม่ใช่การ tune} โมดูล reference ไม่มีฐานสำหรับ
ปริมาณนี้ รายงานนี้สร้างฐานขึ้นด้วยวิธีเดียวกับที่โปรเจกต์สร้างฐานอื่น ๆ
คืออัตราที่ส่วนเบี่ยงฐานจะถูก traversed ภายในหนึ่ง on-dwell
\begin{equation}
\mathrm{RoCoV}_{\text{base}} \;=\;
\frac{\texttt{severity\_dV\_base}}{\texttt{severity\_T\_d\_on}}
\;=\; \frac{0.10\pu}{0.10\ \mathrm{s}} \;=\; 1.0\ \mathrm{pu/s}.
\label{eq:rocovbase}
\end{equation}

\paragraph{ขอบเขต} ขนาดแรงดันบัสถูกบันทึกด้วยสัดส่วน NaN $0.00\%$ ตลอด $3679$
sample \measured{} --- มีอยู่ทั้งสองโหมดและทุกคอนเวอร์เตอร์ ต่างจาก RoCoF
RoCoV จึงระบุตัวได้ทั้งฝั่งตัวตามและฝั่ง former และเป็นตัวเดียวในสองตัวที่
\emph{อาจ} รับหน้าที่ฝั่ง augment ได้

\paragraph{หลักฐานที่วัดได้} สองผลเป็นตัวกำหนดบทบาทของมัน

\begin{enumerate}[leftmargin=1.9em]
\item \textbf{มันไม่เคยถึง dwell ที่โปรเจกต์ต้องการ} ตอน fault บัส 9 เคลียร์
      อัตราไปถึง $998.2$, $975.7$, $1028.5$ และ $1026.7$\,pu/s บนคอนเวอร์เตอร์
      สี่ตัว ($p_{99}$ ตลอด run คือ $81.7$--$86.6$\,pu/s) แต่
      \emph{excursion ที่ต่อเนื่องยาวที่สุดเหนือฐานที่สร้างขึ้น ในที่ใดก็ตามใน run
      คือ $0.0369$\,s} --- $0.37$ เท่าของ on-dwell $0.10$\,s ด้วย dwell ของโปรเจกต์
      RoCoV จึงมี excursion ที่ผ่านเกณฑ์ \emph{ศูนย์ครั้ง} ใน run นี้ การวัดบอก
      เช่นนี้ก่อนที่ใครจะลงมือ implement และรายงานนี้ไม่เสนอให้ลด on-dwell
      เพื่อให้มันยิง \measured
\item \textbf{มันแยก index สองเทอมที่ค้างจากความเครียดที่ยังมีชีวิต}
      ตลอด $t = 110.0021 \to 145.0000$\,s --- $34.998$\,s --- การทดสอบ release
      ถูกกันไว้เพราะ $\Ssev_i$ บางตัวยืนที่ค่าไม่เกิน $0.4301$ ซึ่งสูงกว่า
      threshold การ release ที่ $0.35$ ตลอดช่วงเดียวกันนั้น ทุกบัสหยุดเคลื่อนแล้ว:
      $|\mathrm{RoCoV}|$ ที่มากที่สุดบนเกาะคือ $0.6451$\,pu/s ต่ำกว่าฐานที่สร้างขึ้น
      ส่วนเบี่ยงนั้นเป็น offset ที่\emph{นิ่งแล้ว}จากแรงดัน healthy ก่อนเหตุการณ์
      ที่ตรึงไว้ ซึ่งเกิดจากการทริปสาย 6--13 ที่ $t = 110$\,s ไม่ใช่ความเครียดที่
      กำลังวิวัฒน์ ตลอดทั้ง run มี $2239$ จาก $3679$ sample ($60.9\%$) ที่มี
      $\Ssev_i \ge 0.35$ บางตัวขณะที่ทุกบัสนิ่งแล้ว สาเหตุเป็นเชิงโครงสร้าง:
      $J_V$ อ้างอิงกับแรงดัน healthy ก่อนเหตุการณ์ที่ตรึงไว้
      \code{(agsi\_reference\_terms.m:183--188)} การเปลี่ยน topology ใด ๆ
      จึงทิ้ง offset ถาวรที่ index แยกจากความเครียดไม่ออก RoCoV เป็นปริมาณ
      ที่ประกาศอยู่ตัวเดียวที่แยกสองสิ่งนั้น \measured
\end{enumerate}

\paragraph{กฎที่เสนอ} RoCoV ไม่สร้าง trigger เช่นกัน มันเป็นตัวคุณสมบัติของ
การทดสอบ release และของ reference ของเทอมส่วนเบี่ยง
\begin{equation}
\text{sample จะนับเข้า release dwell ก็ต่อเมื่อ }
\max_i |\mathrm{RoCoV}_i| < 1.0\ \mathrm{pu/s},
\label{eq:ruleB}
\end{equation}
และช่วงที่นิ่งแล้วขณะผิด nominal จะถูก \emph{re-reference} --- แทนที่แรงดัน
healthy ที่ตรึงไว้ด้วยค่าที่นิ่งแล้ว --- แทนที่จะถูกแบกไว้เป็นความเครียด
ไม่จำกัดเวลา ทั้งสองส่วนเป็นการเปลี่ยนเชิงโครงสร้างของสิ่งที่เทอมส่วนเบี่ยง
ถูกวัดเทียบด้วย ไม่ใช่การเปลี่ยน threshold $0.35$ และรายงานนี้ไม่เสนอให้ปรับ
threshold นั้นใหม่

\paragraph{เส้นทางตรวจสอบ} เล่น run ซ้ำ แล้วยืนยันว่า (ก) ไม่มี release ใด
ถูกให้ขณะที่บัสใดเคลื่อนเร็วกว่าฐาน --- วัดแล้ว การ release ทั้งสามครั้งเกิดที่
$|\mathrm{RoCoV}| \le 0.019$\,pu/s จึงไม่มีครั้งใดได้รับผล --- และ (ข) ช่วงที่นิ่ง
ยาว ๆ ที่ระบุข้างบนยุบเป็นการ re-reference แทนที่จะเป็นการ release ที่ถูกกัน

      ข้อเสนอ~\ref{prop:superset} และพิสูจน์ว่าข้อเสนอ~\ref{prop:superset}
      มีผลที่สังเกตได้เหล่านั้น นโยบายที่จัดอันดับต่างออกไปและยังอยู่ใน gate
      ความเป็นไปได้ชุดเดียวกันไม่ถูกกีดกัน
\item \textbf{ไม่ได้อ้างว่าสองตัวดีกว่าสี่เสมอ} บันทึก defect มีกรณีที่วัดได้
      ซึ่งสี่ตัวรับ deficit $2.0\pu$ ได้แต่สองตัวรับไม่ได้ ข้ออ้างคือเสถียรภาพ
      และความทนทานไม่ monotone ตามจำนวน ทั้งสองทิศทาง
\item \textbf{ไม่ได้อ้างว่าค่า SCR เป็น rating ความแข็งของ plant}
      สมการ~\eqref{eq:scr} ตามที่ implement อ้างอิงแรงดัน gate ถูกยกเว้นสำหรับ
      ตระกูลโมเดลนี้ และ diagnostic ตัวที่สองใน repository ให้ $4.78$--$7.19$
      สำหรับบัสเดียวกันภายใต้ convention ของ rating ที่ต่างกัน การเปรียบเทียบ
      ใช้ได้ภายใน convention ของตาราง~\ref{tab:scr}
\item \textbf{ไม่ได้อ้างว่าตารางความเป็นไปได้ไม่ขึ้นกับโหลด} ตาราง~\ref{tab:adm}
      คือตารางฐานที่ freeze ไว้ ข้อค้นพบเรื่องโหลด $+20\%$ ที่ยกใน
      หัวข้อ~\ref{sec:allfour} เป็นการวัดแยกจากบันทึก defect ที่ระดับโหลดอื่น
\item \textbf{ไม่ได้อ้างว่า index ทั้งสองถูก implement แล้ว} มันเป็นข้อเสนอ
      การออกแบบ แต่ละตัวมีเส้นทางตรวจสอบที่ระบุไว้และยังไม่มีผลการวัด
      ไม่มีผลลัพธ์ใดในรายงานนี้ที่ขึ้นกับมัน
\item \textbf{ไม่ได้อ้างว่าข้อความเรื่อง basin เป็นการทั่วไป} การเทียบ
      $4358^{\circ}$ กับ $6.6^{\circ}$ วัดบนคู่การเปลี่ยนหนึ่งคู่ กลไกถูกเสนอ
      เป็นคำอธิบายของคู่นั้น ไม่ใช่เป็นกฎ
\end{enumerate}
