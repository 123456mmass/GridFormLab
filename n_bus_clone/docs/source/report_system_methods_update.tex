\begin{abstract}
This report presents the analytical and system-level upgrades made to a MATLAB-based n-bus power system analysis toolkit. The report focuses on solver architecture, the shared case-normalization and result-assembly pipeline, continuation power flow capability, economic dispatch support, benchmark and textbook-reference coverage, and automated regression validation. Its scope is restricted to the solver, core, case, testing, reporting, and export layers; GUI architecture and interaction features are intentionally excluded. The present implementation includes Newton-Raphson and Gauss-Seidel AC power flow, load-scaling and predictor-corrector continuation power flow, and one-bus equivalent economic dispatch. All implemented methods operate on a common analytical pipeline. At the time of writing, the automated regression suite passes all 12 of 12 tests.
\end{abstract}

This document covers only the analytical system layer:

\section{Summary of Analytical Updates}

The analytical core has been evolved from a single-method load-flow script into a reusable n-bus toolkit with common preprocessing and postprocessing stages. The principal updates are as follows:

\begin{enumerate}[leftmargin=1.5em]
    \item A shared case-preparation pipeline was introduced so that all solvers operate on the same normalized system model, net injections, and admittance matrix.
    \item The Newton-Raphson solver was retained as the primary AC power flow method with iterative PV-to-PQ reactive limit switching.
    \item A Gauss-Seidel solver was added with constant acceleration factor support and full convergence tracking.
    \item Two continuation power flow variants were implemented:
    \begin{itemize}[leftmargin=1.5em]
        \item load-scaling CPF using repeated Newton-Raphson solves with adaptive step control,
        \item predictor-corrector CPF using tangent prediction and Newton-based corrector with pseudo-arclength parameterization.
    \end{itemize}
    \item Economic dispatch examples from Hadi Saadat Chapter 7 were added as one-bus equivalent OPF benchmark cases using the lambda-iteration method.
    \item Regression tests were expanded to cover IEEE cases, Saadat textbook cases, CPF nose-point detection, reference catalog integrity, and Q-limit switching behavior.
    \item Reporting and export utilities were centralized so that power balance, line flows, convergence history, and summary metrics are generated consistently across all methods.
\end{enumerate}

\section{Unified Data and Model Logic}

\subsection{Bus Data Format and Net Injection}

The toolkit accepts bus data in the format
\[
[\text{BusNo} \;\; \text{Type} \;\; |V| \;\; \theta^\circ \;\; P_{\text{gen}} \;\; Q_{\text{gen}} \;\; P_{\text{load}} \;\; Q_{\text{load}}]
\]
with optional columns for shunt conductance $G_{\text{sh}}$, shunt susceptance $B_{\text{sh}}$, and reactive power limits $Q_{\min}$, $Q_{\max}$. The case-preparation pipeline automatically pads 8-column and 10-column formats to the full 12-column representation.

Mixed generation and load at the same bus is handled through net injection:
\[
P_{\text{spec}} = P_{\text{gen}} - P_{\text{load}}, \qquad
Q_{\text{spec}} = Q_{\text{gen}} - Q_{\text{load}}.
\]
This convention ensures that a PV bus with local demand, or a PQ bus with embedded generation, does not require a special bus type; instead, the corresponding net injection is used directly in the mismatch equations.

\subsection{Shared Preparation Pipeline}

All solvers call a common preparation function that performs three phases:

\textbf{Normalization.} Bus data is expanded to 12 columns by padding missing shunt and reactive-limit fields with defaults ($G_{\text{sh}}=0$, $B_{\text{sh}}=0$, $Q_{\min}=-\infty$, $Q_{\max}=+\infty$). Line data is expanded to 7 columns by padding missing half-line charging, tap ratio, and phase-shift fields ($B_{\text{half}}=0$, tap$=1$, phase$=0^\circ$). The default system base is $S_{\text{base}}=100$ MVA, $V_{\text{base}}=230$ kV, $f=60$ Hz.

\textbf{Validation.} The pipeline checks: exactly one slack bus, unique bus identifiers, bus types in $\{1,2,3\}$, positive voltage magnitudes, $Q_{\min} \le Q_{\max}$ for every bus, and no zero-impedance lines.

\textbf{Model construction.} The $Y_{\text{bus}}$ matrix is assembled using the standard $\pi$-model with support for phase-shifting transformers: $y_{\text{series}} = 1/(R+jX)$, with tap ratio incorporated as $\text{tap} = t \cdot e^{j\phi}$. Bus shunt admittances are added to the diagonal. The pipeline produces a unified model struct containing bus classification indices, net injections, admittance matrix components, state-vector dimensions, and line endpoint mappings.

\subsection{State Vector Convention}

The Newton-Raphson state vector is
\[
\mathbf{x} = \begin{bmatrix} \delta_{\text{PV+PQ}} \\ |V|_{\text{PQ}} \end{bmatrix}
\]
of length $n_{\text{total}} = n_\delta + n_V$, where $n_\delta$ is the number of non-slack buses (PV and PQ) and $n_V$ is the number of PQ buses. Slack bus angles and voltages, and PV bus voltages, are treated as fixed knowns. Two helper functions manage the mapping between the compact state vector and the full bus-length angle and voltage vectors.

\section{Implemented Methods}

\subsection{Newton-Raphson Power Flow}

The Newton-Raphson solver is retained as the primary AC load-flow method. At each iteration, it evaluates the mismatch vector and solves the linearized system
\[
\begin{bmatrix} \Delta P \\ \Delta Q \end{bmatrix}
= J
\begin{bmatrix} \Delta\delta \\ \Delta|V| \end{bmatrix},
\]
where \(J\) denotes the reduced Newton-Raphson Jacobian associated with the non-slack voltage-angle states and PQ-bus voltage-magnitude states.
Convergence is assessed using the infinity norm criterion $\max|\Delta P, \Delta Q| < \text{tolerance}$ (default \(10^{-6}\)). Voltage magnitudes that would otherwise become non-positive are clamped to 0.1 pu as a numerical safeguard.

Key properties:
\begin{itemize}[leftmargin=1.5em]
    \item shared mismatch evaluation and Jacobian assembly via the core helpers,
    \item support for general n-bus systems including transformers and bus shunts,
    \item convergence history stored per iteration in the result structure,
    \item result postprocessing includes bus voltages, angles, generation, load, line flows, and total losses.
\end{itemize}

\subsection{Reactive Power Limit Switching}

The Newton-Raphson solver implements iterative PV-to-PQ switching to enforce reactive power limits. After each converged NR solve, the algorithm checks all PV buses for reactive generation violations against \(Q_{\min}\) and \(Q_{\max}\) within a configurable tolerance. Any violating PV bus is converted to a PQ bus with reactive generation fixed at the violated limit, and the NR solve is repeated. This outer loop continues until no further violations remain or a maximum number of switching rounds is reached.

The switching behavior is validated through the Saadat three-bus PV case under constrained reactive limits, confirming that:
\begin{itemize}[leftmargin=1.5em]
    \item a PV bus is converted to PQ when $Q_{\max}$ is exceeded,
    \item the reactive generation is clamped at the limit value,
    \item the bus type in the result structure reflects the switch.
\end{itemize}

\subsection{Gauss-Seidel Power Flow}

The Gauss-Seidel solver updates bus voltages sequentially using the classical formula obtained from \(S = V \cdot I^*\) and \(I = Y_{\text{bus}}V\):
\[
V_i^{\text{raw}} = \frac{1}{Y_{ii}} \left( \frac{S_i^*}{V_i^*} - \sum_{j \ne i} Y_{ij} V_j \right).
\]
A constant acceleration factor \(\alpha\) (default 1.4) is applied through successive over-relaxation:
\[
V_i^{\text{new}} = V_i^{\text{old}} + \alpha \left( V_i^{\text{raw}} - V_i^{\text{old}} \right).
\]

For PV buses, reactive power is recomputed from the current network state at each iteration, and the voltage magnitude is reset to the scheduled value after the update. Convergence is checked at the end of each full sweep using the same infinity-norm criterion as the NR solver.

Key differences from Newton-Raphson:
\begin{itemize}[leftmargin=1.5em]
    \item no Jacobian is formed or factored---each bus update is $O(n)$ instead of $O(n^3)$ per iteration,
    \item convergence is linear rather than quadratic, requiring more iterations (typically 50--200 versus 3--8 for NR),
    \item uses the same case-preparation and result-building pipeline for consistent output format.
\end{itemize}

\subsection{Continuation Power Flow: Load Scaling}

The load-scaling CPF method increases system loading using a continuation parameter $\lambda$:
\[
P_{\text{load}}(\lambda) = P_{\text{load}}^0 + \lambda \, dP, \qquad
Q_{\text{load}}(\lambda) = Q_{\text{load}}^0 + \lambda \, dQ,
\]
where $dP$ and $dQ$ default to the base load profile at each bus. At each step, a full Newton-Raphson solve is performed on the scaled system, with the previous solution used as a warm start.

\textbf{Adaptive step control.} If an NR solve fails to converge, the $\lambda$ step is halved and retried, down to a minimum step size of $\lambda_{\text{step}}/16$. If the solve succeeds, the step is increased by a factor of 1.2 (up to the maximum step size). This provides robust tracing near the nose point without requiring explicit Jacobian augmentation.

\textbf{Termination conditions.} The method stops when: $\lambda \ge \lambda_{\max}$, NR fails at the minimum step size, the minimum bus voltage drops below a threshold (default 0.65 pu), or the maximum step count is exceeded.

\textbf{Nose-point detection.} The nose point is identified after the fact as the operating point with maximum $\lambda$ before convergence failure or voltage collapse---it is not detected during the continuation process itself.

\subsection{Continuation Power Flow: Predictor-Corrector}

The predictor-corrector CPF implements full pseudo-arclength continuation, enabling the trace to pass through the nose point and continue onto the lower-voltage branch. The augmented state is $\mathbf{z} = [\mathbf{x}; \lambda]$.

\textbf{Tangent prediction.} At each continuation point, let $\mathbf{J} = \partial\mathbf{S}_{\text{calc}}/\partial\mathbf{x}$ be the power-flow Jacobian and $\mathbf{f}(\mathbf{x},\lambda) = \mathbf{S}_{\text{spec}}(\lambda) - \mathbf{S}_{\text{calc}}(\mathbf{x})$ be the mismatch. The sensitivity of the state to $\lambda$ is obtained by solving
\[
\mathbf{t}_x = \mathbf{J}^{-1} \frac{\partial \mathbf{S}_{\text{spec}}}{\partial \lambda},
\]
where $\partial \mathbf{S}_{\text{spec}}/\partial \lambda = [-P_{\text{dir}};\; -Q_{\text{dir}}]$ is the loading direction vector. The full tangent $[\mathbf{t}_x; 1]$ is normalized to unit length. Direction consistency is enforced by flipping the tangent if its $\lambda$-component would reverse direction relative to the previous step (checked via dot product). The predicted point is $\mathbf{z}_{\text{pred}} = \mathbf{z} + \Delta s \cdot \mathbf{t}$.

\textbf{Newton corrector.} The corrector solves an augmented system that combines the power mismatch equations with an arclength constraint:
\[
\begin{bmatrix} \mathbf{J} & -\partial\mathbf{S}_{\text{spec}}/\partial\lambda \\ \mathbf{t}^\top \end{bmatrix}
\begin{bmatrix} \Delta\mathbf{x} \\ \Delta\lambda \end{bmatrix}
= \begin{bmatrix} \mathbf{f}(\mathbf{x},\lambda) \\ -\Delta s_{\text{arc}} \end{bmatrix},
\]
where the bottom row is the full tangent $\mathbf{t}^\top = [\mathbf{t}_x^\top,\; t_\lambda]$ and $\Delta s_{\text{arc}} = \mathbf{t}^\top (\mathbf{z} - \mathbf{z}_{\text{pred}})$ keeps the correction on the hyperplane perpendicular to the tangent. Convergence requires $\max|\mathbf{f}, \Delta s_{\text{arc}}| < \text{tolerance}$.

\textbf{Adaptive step control.} If the corrector fails to converge, the arclength step is halved and the predictor is retried. On success, the step is increased by a factor of 1.2. This is the same adaptive strategy as load scaling, but applied to the arclength parameter.

\textbf{Nose-point detection.} The nose is detected when the tangent's $\lambda$-component changes sign from positive to negative---this is the exact turning point where $d\lambda/ds = 0$, not a post-hoc estimate.

Compared with simple load scaling, the predictor-corrector method can continue beyond the nose point and is therefore more appropriate for full voltage-stability tracing.

\subsection{Economic Dispatch OPF}

The economic dispatch solver implements the classical generation-cost minimization problem for the one-bus equivalent cases presented in Hadi Saadat Chapter 7:
\[
\min \sum_{i=1}^{N_G} \left(\alpha_i + \beta_i P_i + \gamma_i P_i^2\right)
\]
subject to the total demand balance $\sum P_i = P_{\text{demand}}$ and optional generator limits $P_{\min,i} \le P_i \le P_{\max,i}$.

The method uses the \textbf{lambda-iteration (equal incremental cost)} approach. The optimality condition gives
\[
\lambda = \beta_i + 2\gamma_i P_i \quad \forall i,
\]
which, combined with the power balance, yields the analytical solution
\[
\lambda = \frac{P_{\text{demand}} + \sum_i \beta_i/(2\gamma_i)}{\sum_i 1/(2\gamma_i)}, \qquad
P_i = \frac{\lambda - \beta_i}{2\gamma_i}.
\]
Generator limits are handled using an iterative fix-and-solve strategy: any violating unit is fixed at its active-power limit, the remaining demand is reduced accordingly, and \(\lambda\) is recomputed for the unfixed generators. In the present formulation, this process converges in at most \(N_G\) iterations.

This economic-dispatch benchmark is \textbf{not} a full AC OPF. Specifically:
\begin{itemize}[leftmargin=1.5em]
    \item it optimizes real-power dispatch only---no reactive power, no voltage optimization,
    \item it does not include network constraints or branch-flow limits,
    \item it is designed for textbook economic dispatch validation and instructional comparison.
\end{itemize}

\subsection{Full-Network AC OPF}

The project also includes a separate full-network AC OPF solver,
\texttt{ac\_optimal\_power\_flow}. It minimizes quadratic generator cost while
enforcing AC power-flow feasibility through the project's own Newton-Raphson
solver. The outer optimization is a self-written coordinate pattern search over
controllable generator real-power setpoints and generator voltage setpoints.
No MATLAB Optimization Toolbox, MATPOWER, or other ready-made PF/OPF solver is
used.

The AC OPF enforces:
\begin{itemize}[leftmargin=1.5em]
    \item nonlinear AC real/reactive power balance through internal NR solves,
    \item generator \(P_{\min}/P_{\max}\) and \(Q_{\min}/Q_{\max}\) limits,
    \item bus voltage limits,
    \item optional branch MVA limits.
\end{itemize}

The Saadat IEEE 30-bus case is the primary AC OPF regression case.

\subsection{Shared Pipeline Flow}

Every solver follows the same pipeline:
\begin{enumerate}[leftmargin=1.5em]
    \item \textbf{Prepare}: normalize, validate, build $Y_{\text{bus}}$, construct model struct.
    \item \textbf{Initialize}: set initial state vector from specified voltages and angles.
    \item \textbf{Solve}: iterate (NR, GS, or CPF steps) using shared mismatch and Jacobian helpers.
    \item \textbf{Assemble}: build the standardized result struct (52 fields) from the final voltages, including line flows, losses, and totals.
    \item \textbf{Output}: format reports, export files, and generate plots using the common result structure.
\end{enumerate}

The result struct is the universal output format---it is identical regardless of which solver produced it, enabling direct solver-to-solver comparison and shared export/plotting code.

\section{Reference Basis and Data Provenance}

The results and benchmarks presented in this report draw on three categories of source material, distinguished here to clarify the origin of each numerical value.

\textbf{Published textbook references.}
The Hadi Saadat benchmark cases (Chapter 6 power-flow examples and Chapter 7 economic-dispatch examples) were implemented from the reference values and problem statements in \cite{saadat1999}. The case data were encoded into the project's local case library and are version-tracked through the Saadat reference catalog \texttt{saadat\_reference\_catalog()}. These textbook examples serve as the primary validation basis for both the power-flow and economic-dispatch solvers.

\textbf{IEEE standard test-system data.}
The IEEE 14-bus case was adapted from the MATPOWER \texttt{case14} dataset, itself converted from an IEEE Common Data Format file \cite{matpowercase14,matpower2011}. The local case loader records this lineage explicitly in its header comment and in the case-data construction.

\textbf{Toolkit-computed outputs.}
All numerical tables and figures in this report were generated by the present toolkit, not copied from external publications. Specifically, the IEEE 30-bus Newton-Raphson results (Tables~\ref{tab:ieee30-summary} and~\ref{tab:ieee30-bus-sample}), the predictor-corrector CPF plot (Fig.~\ref{fig:cpf-ieee30}), the economic-dispatch results (Table~\ref{tab:opf76-dispatch}), and the NR--GS comparison (Fig.~\ref{fig:nr-gs-batch}) were produced from the project's own solver implementations and export pipeline \cite{localproject2026}.

\section{Conclusion}

In summary, the analytical side of the n-bus toolkit has been upgraded into a structured, regression-tested MATLAB framework for steady-state power system analysis. The current implementation supports five analytical methods built on a common preparation and result-building pipeline, two CPF variants with different continuation characteristics, textbook-backed economic dispatch capability, and benchmark validation against IEEE and Hadi Saadat references. The fact that all twelve regression tests currently pass provides evidence of internal consistency across the implemented solver stack.
